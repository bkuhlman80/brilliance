# **The Evolutionary Embodied Information Processor Stack**

## **A Summary for Continuing Conversations — April 2026**

**Context:** This document summarizes a theoretical framework designed to be self-contained enough to kick off a new conversation without requiring the full history. The framework is part of a book project titled *Bramble: A Brief History of Personality*.

---

## **The Core Idea**

Information processing didn't start with brains and doesn't stop with skulls. There is a single evolutionary stack of embodied information processing systems, running from the living cell to culture itself. Each level inherits everything from the levels below and adds a new computational capability that transforms what the system can do.

The stack has seven levels. The integer boundaries (0→1→2→3) mark genuine phase transitions in the *kind* of processing happening. The sub-levels (0, 0.1, 0.2, 0.3) capture important structure within the pre-model regime.

---

## **The Stack**

### **System 0 — The Living Cell**

**Substrate:** Single cell. Biochemical signaling, gene regulation, metabolic networks.

**What it does:** Self-maintenance. The original allostatic system — the cell continuously regulates its internal state relative to external conditions. This is information processing in the most fundamental sense: detecting environmental signals, transducing them into internal states, and producing adaptive responses.

**What it adds to the stack:** The foundation. Everything above is built on cellular information processing. Every neuron is first a cell.

---

### **System 0.1 — The Multicellular Organism**

**Substrate:** Cell-cell communication, differentiation, immune system, hormonal signaling.

**What it does:** Division of labor and coordination across parts. Individual cells sacrifice autonomy for collective function. The immune system is an information processing network that learns, remembers, and adapts — without any neurons at all.

**What it adds to the stack:** Coordination across components. The first superorganism (a body is a colony of cells that learned to cooperate). This is the template for every subsequent level of collective information processing, including human civilization.

---

### **System 0.2 — The Bilaterian Brain**

**Substrate:** First centralized nervous systems, first monoamines (serotonin, dopamine, norepinephrine), reflex arcs.

**What it does:** Centralized sensory→motor coordination. Bilateral body plan creates a front end (sensing) and a back end (acting), with a central processor connecting them.

**What it adds to the stack:** Affect — the most basic layer of behavioral organization. Valence (good/bad) and arousal (high/low) create a two-dimensional state space. Behavioral states resolve into three modes: escape, exploit, satiate.

**First personality trait:** Individual differences in the balance between approach and avoidance produce **Boldness** — a single trait dimension observable in organisms as simple as fish and insects.

**Computational vocabulary:** Steering, cybernetics, explore/exploit (foraging theory), approach/avoid.

---

### **System 0.3 — The Vertebrate Brain**

**Substrate:** Basal ganglia, HPA axis, amygdala, hippocampus. First telencephalon.

**What it does:** Model-free reinforcement learning (actor-critic architecture). Operant conditioning — the animal learns stimulus→action→reward associations and stores them as habits. No internal model of the world; just cached value functions.

**What it adds to the stack:** The gamification of the lifespan. Operant conditioning elaborates the single boldness dimension across **five fundamental life tasks** (after Kenrick et al., 2010, with base level redefined as allostasis):

1. Allostasis (dynamic self-regulation, not static setpoint defense)  
2. Self-Protection  
3. Affiliation (minimal vertebrate sense: tolerance of conspecifics, proximity regulation — not bonding)  
4. Status (territorial competition, dominance contests)  
5. Mate Acquisition

These emerge in a developmental sequence following life-history theory (Kenrick's stacking pyramid: later-developing systems overlap with rather than replace earlier ones).

**Lines of descent from animal temperament (Réale et al., 2007):**

| Réale temperament | → Life task |
| ----- | ----- |
| Activity | → Allostasis |
| Boldness | → Self-Protection |
| Sociability | → Affiliation |
| Aggressiveness | → Status |
| Exploration | → Mate Acquisition |

All five are **agency-only** — variation in direct behavioral output. There is no warmth pole at this level because there is no simulation machinery to support it.

**Key claim:** Vertebrate personality is agency-only. The remaining two Kenrick tasks (Mate Retention and Parenting) are NOT vertebrate universals — they require the attachment behavioral system, which requires endothermy (System 1).

**Computational vocabulary:** Intent/drives, operant conditioning, model-free RL, actor-critic, plasticity.

---

### **── Phase Transition: 0→1 — From Reactive to Simulative ──**

The transition from System 0.x to System 1 is the first integer boundary. It marks the emergence of *internal models* — the capacity to simulate outcomes before acting. This is the divide between organisms that react and organisms that think (in the intuitive/System-1 sense). It coincides with endothermy (warm blood) and the attachment behavioral system.

---

### **System 1 — The Endotherm Telencephalon (Warm Thinking)**

**Substrate:** Agranular prefrontal cortex ↔ sensory neocortex. (Also present in birds via convergent evolution with different neural architecture — pallium instead of neocortex.)

**What it does:** Model-based reinforcement learning. First-order model of *intent* (a self model) and a world model (Bennett's frontal vs. sensory neocortex distinction). The animal can now simulate different actions before choosing — "do I want rigatoni or would I rather diet?" Slower but more flexible than System 0\.

**Bennett's key distinction:**

| Frontal Neocortex | Sensory Neocortex |
| ----- | ----- |
| A self model | A world model |
| Gets input from hippocampus, amygdala, hypothalamus | Gets input from sensory organs |
| Tries to predict what the animal will do next | Tries to predict what external objects will do next |

**What it adds to the stack — two things simultaneously:**

1. **Simulation machinery** — transforms reactive behavioral responses into sustained behavioral strategies. Sustained strategies with stable individual variation ARE personality traits.

2. **The attachment behavioral system** — enabled by endothermy (thermoregulation, suckling, prolonged developmental dependency). Warmth is literally warm-blooded. Cuddling, suckling, sharing food — warm-blooded parenting activities. Parenting is the evolutionary task form of the attachment behavior system.

**The arrival of Warmth:** These two innovations together unlock the warmth pole of personality. The animal can now *represent* another agent's state and be affected by it.

**Key claim: Agency and warmth aren't two different goals — they're two different computational strategies applied to the same goals.**

* Agency mode (System 0): Direct behavioral action — I fight, I flee, I explore  
* Warmth mode (System 1): Representational engagement — I worry about safety, I maintain bonds, I invest in the future

**The life task menu expands from 5 to 7\.** Mate Retention and Parenting come online. All seven tasks now have both agency-side and warmth-side expressions.

**Temperature mapping (after Joshua Greene's hot/cold morality):** System 1 is "warm" thinking — built on emotional and interoceptive inputs. It simulates *how things feel*. Greene's "hot" moral judgments (fast, emotional, empathy-driven) are System 1 outputs. This aligns with Kahneman's intuition — but Kahneman's "System 1" conflated genuine reflexes (our System 0\) with learned intuitions built on internalized models (our System 1). The phylogenetic staircase separates them.

**Stanovich alignment:** System 0 \= autonomous mind (TASS). System 1 \= algorithmic mind. System 2 (below) \= reflective mind.

**Lines of descent extended — Réale → Kenrick → personality aspects (agency-side):**

| Réale temperament | → Life task | → Personality aspect |
| ----- | ----- | ----- |
| Activity | → Allostasis | → Energy |
| Boldness | → Self-Protection | → Withdrawal (reversed) |
| Sociability | → Affiliation | → Politeness |
| Aggressiveness | → Status | → Assertiveness |
| Exploration | → Mate Acquisition | → Openness |

The warmth-side facets emerge across all 7 tasks at this level (specific labels to be developed).

**Computational vocabulary:** Executive functions, simulation, model-based RL, naive physics/biology/psychology, attachment, deliberation vs. intuition.

---

### **── Phase Transition: 1→2 — From Modeling the World to Modeling Minds ──**

The second integer boundary marks the emergence of *recursive* modeling — the capacity to model other minds that are themselves modeling you. Mentalizing. Metacognition. This coincides with the agranular→granular PFC cytoarchitectural transition.

---

### **System 2 — The Ape Prefrontal Cortex (Cold Thinking)**

**Substrate:** Granular prefrontal cortex ↔ STS & TPJ. Full six-layer cortical architecture.

**What it does:** Second-order model of *mind*. Mentalizing, metacognition, Machiavellian intelligence. "Cold" calculation. The primate brain models *why I have the goals I have* and *why you have the goals you have*. Common knowledge: I know that you know that I know.

**Bennett's predictive processing architecture:** Each layer wraps around and "tries to explain" the one below:

| Layer | Hardware | Model type |
| ----- | ----- | ----- |
| System 2 (primate) | gPFC ↔ STS & TPJ | 2nd-order model (mind): tries to explain System 1's intentions |
| System 1 (mammal) | aPFC ↔ sensory cortex | 1st-order model (intent): tries to explain System 0's reward signals |
| System 0.3 (vertebrate) | Basal ganglia, amygdala, hippocampus | Model-free learning from reflexes and sensory input |
| System 0.2 (bilaterian) | Reflex arcs | Direct sensory→motor connections |

**What it adds to the stack — the 2→3 split:**

Cold/strategic cognition splits the Big Two (Warmth ↔ Agency) into **three** universal social cognitive dimensions:

* **Warmth** → **Affiliation** (warm \+ strategic)  
* **Agency** → **Autonomy** (cold \+ self-directed) \+ **Mastery** (cold \+ other-evaluated)

This split occurs because Machiavellian intelligence creates a distinction between two kinds of competence: *autonomy* (acting independently, resisting social pressure) and *mastery* (demonstrating competence the group recognizes). Without metacognition, warmth is undifferentiated caring. With it, you can distinguish bonding (affiliation) from self-governance (autonomy) from skill demonstration (mastery) — because you can model your own goals as distinct from the group's.

**HEXACO mapping (reordered):**

| Primate dimension | → HEXACO factors |
| ----- | ----- |
| Autonomy | → H (Honesty-Humility), O (Openness) |
| Affiliation | → X (Extraversion), A (Agreeableness) |
| Mastery | → C (Conscientiousness), E (Emotionality) |

**Self-determination theory (Deci & Ryan)** — rooted in existentialism and humanism — maps directly: Autonomy, Competence/Mastery, Relatedness/Affiliation as the three basic psychological needs.

**The Venn diagram:** The three primate dimensions form a Venn with intersection zones defining facet centrality/periphery. Center-zone traits require simultaneous coordination of all three systems → predicts nonadditive genetic variance gradient (primaries \> intersections \> center in additive heritability). Nearly all facet-level architecture is in place at the primate level before humans arrive.

**Temperature:** System 2 is "cold" — Greene's utilitarian moral judgments, strategic social maneuvering, calculated prosociality. It can override System 1's warm intuitions.

**Computational vocabulary:** Mentalizing, metacognition, common knowledge, Machiavellian intelligence, self-determination theory.

---

### **── Phase Transition: 2→3 — From Inside Skulls to Between and Beyond Them ──**

The third integer boundary marks the transition from information processing *inside individual brains* to information processing *distributed across brains and externalized into artifacts*. The superorganism gets its own nervous system.

---

### **System 3 — Culture Itself (The Superorganism's Nervous System)**

**Substrate:** Languages, writing systems, libraries, institutions, the internet. Wernicke's area and Broca's area as the individual-level interface.

**What it does:** Symbolic (arbitrary) semiotics — sign-object pairings grounded not in physical resemblance (iconic) or spatiotemporal correlation (indexical) but in relationships between signs themselves (Peirce's triad, per Deacon 1997). Externalized memory, cumulative knowledge, institutional learning.

**What makes symbolic reference different (Deacon):**

* Indexical associations are independent and extinguish when correlations break down  
* Symbolic reference derives from combinatorial relationships *between symbols* — words point to objects (reference) AND to other words (sense)  
* The threshold from indexical to symbolic requires a restructuring event — suppressing immediate associations in favor of higher-order relational patterns  
* Co-evolution: language drove prefrontalization, prefrontalization made language easier. Not special sauce — a scaling threshold.

**What it adds to the stack:**

1. **Symbolic compression.** The alphabet demonstrates the principle: 26 arbitrary signs reconstruct all possible English utterances. Human culture is symbolic information compression, with a driving purpose: **to educate children — to shorten the path to mastery.**

2. **Crystallized semantic knowledge as personality.** Human personality now includes internalized cultural artifacts — knowledge, beliefs, values, narratives, identities. These are individual differences that exist only in a symbolic species.

3. **The superorganism.** Each human mind is part of something bigger. The superorganism (Bloom's *Global Brain*, D.S. Wilson's multilevel selection, Henrich's cumulative cultural evolution) is not a metaphor — it's the next level of embodied information processing on the same stack that started with the cell. The internet is to civilization what the neocortex is to a mammal: a simulation layer that wraps around the lower systems and "tries to explain" them.

**Cumulative culture predates humans and language** — but pre-human cumulative cultures are indexical (Peirce). Only humans have symbolic (arbitrary) object-sign pairings. This is the human superpower.

## **What the Stack Explains**

### **The Generational Cycle**

If the superorganism has emergent behavioral dispositions (System 3 level), do they change? Do they cycle?

A four-phase rotation where each generation's dominant trait profile creates conditions — via parenting — for the next generation to compensate:

1. **Civic Heroes** (high Affiliation, low Autonomy) → raise…  
2. **Adaptive Artists** (high Autonomy, low Boldness) → raise…  
3. **Idealistic Prophets** (high Boldness, low Mastery) → raise…  
4. **Reactive Nomads** (high Mastery, low Affiliation) → raise Civic Heroes.

**Mechanism (abstract):** Allostatic predictive processing (Friston) applied to the superorganism. Trade-offs between the four vertices produce continuous error correction on an attractor landscape.

**Mechanism (practical):** Symbolic compression enables the parenting correction signal to be transmitted culturally — through narratives, institutions, values, educational philosophies. Only a symbolic species can transmit "we overdid X, compensate with Y" across generations. Indexical cultures can *drift*. Only symbolic cultures can *self-correct based on abstract models of their own trajectory*.

**Open question:** The psychometric data (Twenge) shows secular trends, not confirmed oscillation. A hybrid model (after Dalio) may be more accurate: secular trend (cultural ratchet, always increasing complexity) \+ long cycle (\~80 years, generational rotation) \+ short cycles (economic/technological disruptions).

### **The Inheritance Gradient**

As you move up the stack, the channel mix of parent-offspring transmission shifts:

| Level | Dominant inheritance channel |
| ----- | ----- |
| System 0 | Genetic |
| System 0.1-0.3 | Genetic \+ parental effects |
| System 1 | \+ epigenetic \+ social learning (indexical semiotics) |
| System 2 | \+ strategic social transmission (mentalizing enables teaching with intent) |
| System 3 | \+ **symbolic cultural transmission** (becomes dominant) |

Danchin's (2011) "inclusive heritability" provides the formal framework for unifying all channels. Turkheimer's (2014) phenotypic null hypothesis provides the air cover: massive polygenicity means the developmental environment (including culture) does real causal work on personality.

### **The "Tries to Explain" Principle Scales All the Way Up**

Bennett's predictive processing architecture — each layer wrapping around and trying to explain the one below — doesn't stop at the individual brain. Culture "tries to explain" collective human behavior, detects prediction errors (this generation's excesses), and generates corrections (next generation's compensatory values). It's "tries to explain" all the way from the cell to civilization.
