## **BC-BNT-COMP-02: Parameterized Generalism Predicts Different Representations Under Different Training Regimes**

**Placement:** COMP, near existing Modularity Position section.

(Triggered by convergence of COMP-MTL-REP-01, COMP-MCG-MHE-01E, COMP-HOF-SLO-01, and existing COMP-WAN-GBF-01 \[Wang bifurcation framework\].)

The HPAM modularity position bets on parameterized generalism: a shared canonical circuit template whose parameters vary along systematic gradients. Wang's bifurcation framework shows how quantitative parameter differences produce qualitatively different computational behaviors from the same circuit.

The broad vs. narrow training extraction adds a training-regime dimension to this position. The same parameterized architecture, trained on different input distributions, produces representations with systematically different properties:

Narrow training → locally optimized parameters → high within-domain performance → representations that encode surface features and domain-specific correlations → McGilchrist's left-hemisphere "local communication within regions" → Hofstadter's "truncated corridor" of limited representations.

Broad training → abstractly tuned parameters → lower peak performance on any single task → representations that encode structural regularities across input distributions → McGilchrist's right-hemisphere "greater white matter connectivity across regions" → Hofstadter's "infinite corridor" of nested, extensible categories.

This is not a metaphor. It is a direct prediction from the architecture: if the cortex is a parameterized system whose representations are shaped by input statistics, then the training distribution *determines* the representational properties. The same person, raised in a broad developmental environment vs. a narrow one, should show measurably different representational organization — more abstract, more connected, more transferable in the broad case; more domain-specific, more efficient within-domain, more brittle in the narrow case.

This convergence across three independent literatures (ML representation learning, McGilchrist neuroanatomy, Hofstadter computational philosophy) strengthens the parameterized generalism position by adding a dimension Wang's bifurcation framework doesn't address: not just gradient variation across cortical regions, but training-dependent variation within the same regions.

**COMP-MTL-REP-01 \[MECHANISM\]**

**Claim:** In multi-task learning, multiple outputs share a common hidden layer, creating a representation bias where backpropagation is pulled toward the intersection of representations preferred by all tasks, rather than a local minimum optimal for just one.
