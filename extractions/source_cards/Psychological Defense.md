**Claim:** Hart (2014) proposes a “security system” model integrating Terror Management Theory, attachment theory, and system justification into a unified framework centered on security maintenance. The core claim: worldviews, close relationships, and self-esteem form a coordinated network that provides an “anxiety buffer” against generalized threats. When one component is bolstered, defensiveness to threats in other domains is reduced — “fluid compensation.” Bolstering attachment security (e.g., priming secure-base schemas) attenuates worldview defense and out-group derogation. Bolstering self-esteem (e.g., positive personality feedback) reduces mortality salience effects. The model proposes that all psychological threats share a nucleus of “anxious uncertainty” or “apprehension about personal vulnerability.” Diverse stimuli — mortality reminders, absurdist humor, anomalous word pairings, attachment insecurity, system instability — trigger the same defensive rigidity because they all disturb the security network.

**MASK-HRJ-SSM-02 `[MECHANISM]`**

**Claim:** Hart (2014) identifies three conditions under which cross-domain buffering breaks down, suggesting the security system’s components are not perfectly interchangeable. (1) Functional specificity: some threats elicit highly specific defenses that general security boosts cannot satisfy — threats to personal control sometimes produce different reactions than mortality reminders. (2) Developmental precedence: attachment security emerges before symbolic worldview defense, and attachment defenses can “trump” self-esteem or worldview defenses — suggesting the system has a developmental hierarchy, not a flat structure. (3) Authenticity requirement: individuals with high explicit but low implicit self-esteem show *increased* defensiveness under threat, suggesting that a “strong” security domain can be a defensive weakness if the security is not genuine. The model predicts “spreading activation” — weakening one component should undermine security across the entire network. If an individual could remain secure in their worldview while their self-esteem and relationships are in disarray, the unified model would be falsified.

**Relevant to:** Developmental hierarchy of the security system (attachment is foundational — constrains the architecture), authenticity as moderator (defensive self-esteem doesn’t buffer — connects to existing MASK containment masking where the person’s “security” is built on a false self), existing MASK three-outcome model (the security system’s breakdown conditions map onto which outcome occurs — functional specificity determines which defensive output fires, developmental precedence determines recovery order)
