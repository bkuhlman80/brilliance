# Function-Description Reference

Algorithmic reference for Test 1 function descriptions in the pair and triple label audit. The relation between two motivations — not the cell — is the unit of description. Each relation is generated once, when the younger participant is just-born, and persists thereafter. Cell tables are reference views into the relations index. Discipline content enters only at the candidate-evaluation stage that follows.

## Lookup tables

### Table A — Slot-verb rule

Each row-slot has a fixed cybernetic verb. The younger participant in any pair fires its slot-verb on the older. Direction is determined by birth-order, not by row-slot position in the rolling window.

| Slot | Template (firer → older sibling) |
|---|---|
| R1 | `[firer] drives [target] outward` |
| R2 | `[firer] stabilizes [target] across instances` |
| R3 | `[firer] informs [target]` |
| R4 | `[firer] revises [target]` |

## Triple cell-view table

12 levels × 4 triples. Triples retain `Absent-R1/R2/R3/R4` as structural identifiers. The conceptual content is the chain among the three present primaries.

**Chain generation rule.**
1. For triple T at level L, identify the 3 present primaries (the 4 foreground motivations at L minus the absent-slot's occupant).
2. Sort the 3 by birth-order. The middle one is the chain hub.
3. Render: `[youngest's slot-verb on middle], which [middle's slot-verb on oldest]`. For R2 in middle position, the second segment ends with "across instances". For R1 in middle position, the chain becomes `..., which drives [oldest] outward`.

Function classes for the four triples: Planner = deliberative planning; Pursuer = adaptive goal-pursuit; Reactor = reactive control; Conservator = anticipatory homeostasis.

## Notes on use

**The slot-verb rule.** Each row-slot has a fixed cybernetic verb (R1 drives outward, R2 stabilizes across instances, R3 informs, R4 revises). The younger participant in any pair fires its slot-verb on the older. Direction is determined by birth-order, not by row-slot position in the rolling window.

**Relations are established once.** A relation is introduced at the level when its younger participant is just-born and persists in the stack thereafter. Pair cell-views display whichever relations have both participants currently in the rolling-window foreground; they do not generate new relations.

**Persistence as cell-equality.** A label's persistence in the rolling window is visible as repeated occurrence in consecutive cells of the same column.

**Diagonals.** Some triple chains pass through pair-relations not shown in the pair cell-view table; these are diagonal pairs in the Venn — present in the architecture, not visible in the top-view rendering. The relations index lists them.

**Triples describe what's present.** Triple identifiers (Absent-R1, etc.) are structural tags identifying which slot is excluded. The triple's content is the chain of relations among the three present primaries.
