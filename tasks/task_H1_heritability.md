# Task H1: Univariate Heritability by Bright Triad Zone

## Reference
See `bright_triad_reference.md` for the model description and zone assignments.

## Hypothesis
Primary-core facets (those in the ES or E circles with no overlap) are more heritable than intersection-zone facets (those in the purple, orange, or brown overlap zones), which are in turn more heritable than center-triangle facets (Brilliance zone).

## Prediction
Mean heritability: Primary cores > Intersection zones > Center triangle

## Data needed
Univariate heritability estimates (h²) for individual NEO-PI-R facets from twin studies or family/pedigree studies. Look for:
- Classical twin study ACE/ADE model estimates
- Extended pedigree study estimates
- Cross-cultural replications of facet heritability

Report the estimate, the sample, and any noted instability across samples. If a facet's heritability varies substantially across studies, report the range.

## Analysis
1. Build a table: one row per facet, columns for heritability estimate(s) and Bright Triad zone assignment.
2. Compute zone means (mean heritability per zone). If ranges are given, use midpoints.
3. Compare: does the predicted ordering hold?
4. Report within-zone variability — if one zone's facets range from .20 to .70, the zone mean is misleading.

## Output
- Data table with all extracted heritability values and zone assignments
- Zone means with standard deviations or ranges
- Verdict: Supported / Partially supported / Not supported / Untestable
- Caveats (data gaps, instability, alternative interpretations)
