# Task H4: Direction of Cross-Domain Genetic Loadings Matches Bright Triad Parent Predictions

## Reference
See `bright_triad_reference.md` for the model description and zone assignments.

## Hypothesis
When intersection-zone facets cross-load genetically on other domains, those cross-loadings should point toward the predicted parent domains — not randomly across all domains.

## Predictions by intersection zone

**Conscientiousness facets (I∩ES zone: C1, C4, C2, C6, N5):**
These should cross-load on:
- N / reversed-N (the Emotional Stability parent) ← predicted
- O (the other domain that shares the Intelligence parent) ← predicted
They should NOT primarily cross-load on E or A.

**Openness facets (I∩E zone: O2, O3, O1, O4):**
These should cross-load on:
- E (the Extraversion parent) ← predicted
- C (the other domain that shares the Intelligence parent) ← predicted
They should NOT primarily cross-load on N or A.

**Agreeableness facets (ES∩E zone: A2, A4, N2, E1):**
These should cross-load on:
- N / reversed-N (the Emotional Stability parent) ← predicted
- E (the Extraversion parent) ← predicted
They should NOT primarily cross-load on O or C (except through specific center-triangle-adjacent facets).

## Data needed
Same genetic factor loadings as H3 — facet-level loadings on all five genetic Big Five factors. For each intersection-zone facet, identify the direction and magnitude of every cross-domain loading.

## Analysis
1. For each intersection-zone facet, list all cross-domain genetic loadings with direction and magnitude.
2. Classify each cross-loading as "predicted direction" (toward a parent domain) or "non-predicted direction."
3. Tally per zone: what fraction of cross-loadings point in the predicted direction?
4. Tally overall across all three intersection zones.

## Output
- Per-facet table: facet, zone, each cross-domain loading, classification (predicted/non-predicted)
- Per-zone tally: % of cross-loadings in predicted direction
- Overall tally
- Verdict: Supported (>70% predicted) / Partially supported (50–70%) / Not supported (<50%)
- Note any facets that strongly violate predictions (cross-loading in non-predicted direction with large magnitude)
