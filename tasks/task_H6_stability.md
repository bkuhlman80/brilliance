# Task H6: Developmental Rank-Order Stability by Bright Triad Zone

## Reference
See `bright_triad_reference.md` for the model description and zone assignments.

## Hypothesis
Primary-core facets (those in the ES or E circles with no overlap) show higher developmental rank-order stability than intersection-zone or center-triangle facets. The logic: biological primaries should be more resistant to environmental perturbation.

## Prediction
Mean rank-order stability: Primary cores > Intersection zones > Center triangle

## Data needed
Rank-order stability estimates at the facet level. These are test-retest correlations (or latent stability coefficients) for individual NEO-PI-R facets across time intervals. Look for:
- Latent stability coefficients from longitudinal studies
- Test-retest correlations at the facet level
- Meta-analytic stability estimates if available at facet level
- Any data on differential stability (some facets more stable than others)

Note: most stability data in the personality literature is reported at the domain level, not the facet level. If facet-level stability data is not available, report this clearly.

## Analysis
1. Collect any facet-level rank-order stability estimates.
2. Assign to Bright Triad zones.
3. Compare zone means.
4. If insufficient facet-level data exists, check whether domain-level stability patterns are at least consistent with the prediction (i.e., N and E domains — the primaries — are more stable than C, O, and A domains — the intersections).

## Output
- Data table with any facet-level stability estimates found
- Zone comparison if possible
- Verdict: Supported / Partially supported / Not supported / Untestable
- If untestable, state what data would be needed
