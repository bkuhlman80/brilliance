# Task H9: Facets Outside All Circles Show the Weakest Biological Signatures

## Reference
See `bright_triad_reference.md` for the model description and zone assignments.

## Hypothesis
Facets placed outside all three circles (A5 Modesty, O6 Values) and at the edges (C5 Self-Discipline, E5 Excitement-Seeking) should consistently show the weakest biological signatures across multiple indicators. This is a negative-space prediction: the Bright Triad says these facets don't belong to any part of the core mental phenotype structure.

## Prediction
A5, O6 (and to a lesser extent C5, E5) should show:
- Lowest or most anomalous heritability estimates
- Lowest cross-cultural genetic stability (loadings that vary most across samples/countries)
- Flattest developmental trajectories (least mean-level change across adulthood)
- Highest facet-specific genetic variance (most of their variance is "their own thing," not shared with domain-mates)
- Exclusion from streamlined instruments (BFI-2 excluded them)
- Weakest or most anomalous genetic factor loadings

## Data needed
For A5, O6, C5, and E5 specifically, collect ALL available biological indicators:
- Heritability estimates (any source)
- Genetic factor loadings across countries
- Cross-cultural stability of genetic loadings
- Developmental trajectory descriptions
- Facet-specific genetic variance
- BFI-2 inclusion/exclusion status
- Any molecular genetic associations
- Life satisfaction correlations
- MZ/DZ twin correlation patterns (any anomalies like reversed patterns)

Also collect the same indicators for a comparison set — pick 4 facets from different zones that are clearly well-placed (e.g., N1, E2, C1, A2) and compile the same data for comparison.

## Analysis
1. Build a profile table for A5, O6, C5, E5 — one column per biological indicator, one row per facet.
2. Build the same table for the comparison facets.
3. For each indicator, compare: are the outside-circle facets consistently at the extreme?
4. Count how many indicators show the predicted pattern for each outside-circle facet.

## Output
- Profile table for outside-circle facets
- Profile table for comparison facets
- Indicator-by-indicator comparison
- Overall verdict: Supported (consistently weakest) / Partially supported / Not supported
- Note which specific facets and indicators deviate from prediction
