## The stage at a glance

| | |
|---|---|
| Function | **Effector** |
| Site movement | understory → canopy |
| Process | Loaded to Expressed |
| Selection bias | recency |
| Two bits | blind and bounded |
| Question it asks | can it be built |
| Discard class | failed builds and heat |

**Why the bits fall this way.** Blind, because a build runs its instructions without reading outcomes. Bounded, because what one set of instructions can build is a finite region. That is the Effector corner of the reflexivity square, and it was read off the stage independently of the theme mapping.

A process names an operation and the space it runs in, because neither half specifies it alone. The space is the domain the criterion is defined over, not the subset the criterion picks out.

## What belongs here

**Expression is selection's home.** The canopy contest happens now or it is not a contest, which is why the bias is recency and why a selective event is maximally present-tense.

**Both narrative retellings go soft here, and it is the same clade twice.** The Unraveling and Act 2B are the weakest entries in the retellings table. Expression is the stage with the least agency available anywhere in the cycle, and two independent traditions going vague exactly where a story would need a protagonist is worth reading as corroboration for the framework's refusal to supply one.
