# Dialect Bank — 50 phonology/lexical lines per voice

*Companion to voice_bank_100.md. Every line carries a documented feature from the dialectology reference — roughly half phonology, half lexicon per character. Tagged for adjudication. **This is a palette, not a prescription**: the fork's rarity rule still governs deployment; at full density this would be costume. Strike tokens freely.*

*Rendering conventions: mergers > droppings (per the egg rule); glottal oral release rendered with apostrophe ("moun'n"); merger lines mostly played as near-homophone confusion, self-repair, or metacommentary rather than raw respelling.*
