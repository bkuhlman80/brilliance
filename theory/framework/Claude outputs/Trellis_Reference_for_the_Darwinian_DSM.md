# The Trellis Framework: A Reference for the Darwinian DSM

The Trellis Framework is a theory of where behavior comes from. It holds that every living thing, and some built things, runs on the same small set of jobs, and that those jobs appeared one at a time over evolutionary history. Each new job was layered on top of the older ones without replacing them. An animal's behavior, healthy or disordered, can be read as the output of that layered stack.

This reference covers the parts of the framework that a cross-species psychiatry can build on:

1. the four basic jobs, and how to tell which ones a behavior needs;
2. how the jobs were added over time, and the seven combinations an animal has;
3. a set of rules for talking about evolution without fooling yourself;
4. the four kinds of thing that get inherited, with the learned behavior pattern treated in full;
5. the animal line, stage by stage, with every combination filled in and cited;
6. how the stack fails, and why;
7. how to use evidence from any species.

---

## Key terms

These words carry specific meanings throughout. Each is also explained where it first does real work.

- **Function.** One of four basic jobs a living system can do: act, hold a standard, learn from its own experience, or communicate in a shared code. A function is a job, not a body part. One structure can do more than one job.
- **Slot.** A combination of functions working together, such as "acting plus holding a standard." Every mechanism in an animal can be assigned to the smallest slot that covers everything it needs.
- **Venn.** The overlapping-circles diagram the framework uses to draw the slots. Each circle is a function; each region where circles overlap is a slot. It is a picture of the combinations and nothing more.
- **Line.** One of four long chapters of evolutionary history, each defined by a new kind of inheritance: genes, then learned behavior, then language and culture, then software.
- **Clade.** A group of organisms that share a common ancestor, used here as a waypoint along one path of descent. The four waypoints of the animal line are Bilaterian, Vertebrate, Endotherm and Primate.
- **Grade.** A group defined by a shared level of organization rather than a shared ancestor. Endotherm (warm-blooded) is a grade: mammals and birds both became warm-blooded, separately.
- **The thread.** The one line of descent the framework traces, from the earliest cells to humans. Every other lineage (dogs, parrots, octopuses, bees) branched off the thread at some point and is called **off-thread**.
- **Store.** Wherever a system keeps information it can use later: a genome, a set of learned habits, a vocabulary.
- **Write-back.** A store being changed by what the animal itself just did and experienced, so that it responds differently next time. Write-back is the framework's definition of learning.
- **Neme.** A learned behavior pattern, treated as the thing that gets inherited within one lifetime. The animal-line counterpart of the gene.
- **Drive.** The name for a function as it shows up at a particular stage of evolution, such as Impetus (the animal-line drive to act). A drive is a dimension along which individuals differ, not a wish or a goal.
- **Eclipsing.** What happens when a newer layer of behavior goes quiet and an older layer shows through. Eclipsing is the framework's account of regression under stress.

## 1. The four functions

A function is a job, not a part. A pump that keeps salt levels steady, a synapse that holds a learned connection, a muscle that contracts and a word that leaves a mouth are all matter doing something. What makes each one a function is what the animal would lose if that job stopped. A single structure can do more than one job.

No function involves intention. An animal "wants" things only in the sense that a thermostat "wants" a temperature. When this document says something exists "for" a purpose, it means the arrangement pays off for the lineage that carries it, and that nobody, the animal included, needs to understand why.

There are four functions. Three of them are kinds of memory; the first is the doing that comes before any memory.

| Function | Its job in plain terms | What it keeps | How to tell it is present |
|---|---|---|---|
| **Effector** | Doing: moving, building, carrying, transforming, secreting, emitting, pulling apart | Nothing. It is the raw activity that was there before any memory | The mechanism does something that cannot be fully described as holding, learning or communicating |
| **Regulator** | Holding a standard: keeping a stored value and checking against it | A reference value the system can fall short of, such as a set point, a floor, or an expectation | The mechanism consults a stored value it could be wrong about. Merely staying in a stable state does not count |
| **Modeler** | Learning from its own experience: changing a store based on what the animal's own actions ran into | A store that experience rewrites | After the experience the animal responds differently to the same situation, and the change lasts after the experience is over |
| **Translator** | Communicating in a shared code: putting what one holds into a form another individual can take up and pass on | The shared code itself, such as a vocabulary | What passes between individuals is in a code that anyone can reproduce, that has distinct units its users correct toward, and that the individuals share without sharing anything else |

Two of these definitions do most of the work in a clinic.

**Learning means the animal's own experience rewrote a store.** A genome is a model of the world built by a lineage, but the individual animal cannot rewrite it, so it counts as a held standard (Regulator), not as learning. Habituation does count as learning: after repeated exposure the animal's response to a stimulus lastingly changes. A temporary shift does not count. If a change tracks the current conditions and snaps back when they end, the animal is holding a state, not learning. An animal that adjusts its stress hormones during a drought and meets the next drought exactly as it met the first has not learned anything. One that meets the next drought faster has.

**Communication means a shared code, and no animal on the thread has one before humans.** One animal affecting another is not enough. Every social act changes something inside another animal, and almost none of it is communication in this sense. Grooming, reconciliation, displays, threats, courtship signals, alarm calls and dominance signals all pass between animals that carry models of one another. None of them involves a code that the receiver copies, corrects toward a standard form, and could pass on. Those behaviors belong to the other three functions. Direct biological transfer, such as a gene passed between bacteria, is not communication either.

Copying shows the distinction clearly. An animal that copies whatever gets the food is being taught by the food, and no shared code is involved. An animal that copies the exact steps a model performed, including steps that did nothing, is matching a standard form, and that form is a code. Copying useless steps (over-imitation) looks irrational, but it is the signature of a real shared code. Children over-imitate; most other animals do not.

**Assigning a mechanism to a slot.** A mechanism goes in the smallest slot whose functions it actually needs. Three rules keep this honest.

- **Assign what it does now, not how it got there.** A habit that was learned but now runs on autopilot is assigned as the autopilot loop, not as the learning that built it.
- **Assign what it requires, not what its description mentions.** A description that names a function the mechanism could run without has said too much.
- **Judge "doing" last.** When a mechanism combines several jobs, first account for any holding, learning or communicating. Whatever doing is left over is the Effector. Correcting toward a set point belongs to the Regulator no matter what physical form the correction takes. A pump that moves salt to keep a level steady is a Regulator. An animal that walks into the shade to cool down is doing something more than correcting, and that walk counts as action.

## 2. How the functions were added over time

The framework's diagram grows. Each long chapter of evolution added one new function. The new function split off from the center of the diagram, the region where all existing functions overlap and the whole system is running at once. A new kind of memory can only be tested on how the whole organism performs, which is why each one is born at the center.

When a new function split off, the old center was left without it and was renamed for what it still does.

| Stage | Chapter of evolution | Number of slots | What was added | What the old center became |
|---|---|---|---|---|
| 0 | Before cells: self-sustaining chemistry | 1 | — | A **process** that keeps itself going |
| 1 | The genetic line: cells | 3 | **Regulator** (holding a standard) | The process became the **Effector**. The new center, act-and-check, is the **Feeder**: a cell taking in what it needs to keep itself going |
| 2 | The nemetic line: animals with brains | 7 | **Modeler** (learning from experience) | The Feeder became the **Controller**. The new center is the **Workspace**: the place where candidate actions compete |
| 3 | The symbolic line: humans with language (and later, software) | 15 | **Translator** (communicating in a shared code) | The Workspace became the **Conservator**. The new center is the **Coordinator**: an individual whose behavior is completed through others |

A slot is any combination of the functions that exist at a stage, so the number of slots goes 1, 3, 7, 15. Each slot has two facts that matter: which functions it combines, and when it first became possible. Every pair of functions forms a feedback loop, because each function is complete at its own job and missing something only another function supplies. Action cannot see its own results; a standard cannot enforce itself or look ahead; a store built from the animal's own experience contains nothing it did not experience; a code has no physical form and nothing to say on its own.

The older stages are not replaced. The three-slot cellular system sits inside the seven-slot animal system as its Controller region. The seven-slot animal system sits inside the fifteen-slot human system as its Conservator region. In this architecture, older layers keep running under newer ones.

### The seven slots every animal has

Every animal on the thread, and every pet off it, is read against these seven.

- **Effector (doing).** Spending the body's resources on a change in the world, with no comparison, no learning and no audience required.
- **Regulator (holding a standard).** A stored value and whatever checks against it. Experience does not revise this value, though evolution or a higher-level system can set it.
- **Modeler (learning).** The store being rewritten by experience, and nothing else: perception updating from surprise, memories being consolidated, the brain choosing what to keep and what to let fade.
- **Controller (act and check, no learning).** Act, compare against a standard, correct. Nothing about the outcome rewrites how the loop works. This is the automatic, model-free route: a fixed mapping from "something is wrong" to "do this." A consolidated habit runs here no matter how it was originally learned.
- **Budgeter (forecast and pre-correct).** A standard informed by a learned model, so the body corrects before a problem arrives instead of after. The loop runs inside the body, through stress hormones, heart rate, digestion and the immune system, rather than through action on the world. This is the body run on a forecast. Its signs are adjustment in advance of demand, set points that shift with expected load, and an internal model of something (a caregiver, a rival, a meal) whose predicted state has consequences for the body. It runs in both directions: the model can inform the standard, or the standard can grade the model.
- **Connector (act and learn, no standard).** Action guided by a learned model, with the model updated by what the action finds, and no standard grading the result. This is model-based action, where the animal perceives by acting and acts on what it perceived. The clearest case is exploration with no reward: an animal wanders, learns the layout, and uses it later. The model can include the animal itself, and it can include other animals. Social life is what this loop becomes when the model contains other individuals.
- **Workspace (act, check and learn together).** The arena where candidate actions from all three kinds of loop compete for control of one body. A body can do only one thing at a time, so something has to decide. Its signature operation is full reinforcement learning: act, compare the outcome with what was expected, and rewrite the store that produced the act. The difference from the Connector is the standard: add an expectation that grades the outcome, and exploration becomes reinforcement.

At the human stage these seven become one region of fifteen. All eight new slots involve the shared code, and on the thread none of them is available to any animal before humans.

### What each stage added

Each stage added one new property to memory.

| Stage | What was added | In plain terms |
|---|---|---|
| Before cells | Doing | Chemistry that keeps itself going |
| Cells | Memory | A stored standard the cell is held to |
| Animals | Revisable memory | A standard the animal rewrites from its own experience |
| Humans | Shareable memory | A standard put into a code so another person can take it up |
| Software | Self-running plans | A written plan executed by a machine built to follow it |

A cell's genetic store is walled off: nothing that happens to the body changes the genes it passes on. Biologists call this Weismann's barrier. The arrival of learning took that wall down inside the individual animal. The animal line is the first in which what happens to an individual changes what it carries forward, which is what "Lamarckian" means. The order of the stages is walled, open, open, open.

### The stages and their waypoints

Each line of evolution is a population where something varies, something is tested, and something is copied. Each line's raw material was laid down at the end of the line before it. The animal line could begin only once nerve tissue existed, and the human line could begin only once animals could model other minds and make tools.

| Line | Waypoints, in order | What the last waypoint laid down |
|---|---|---|
| Genetic (cells) | Prokaryote · Archaeon · Eukaryote · Eumetazoa (animals with tissues) | Nerve tissue |
| Nemetic (animals with brains) | Bilaterian · Vertebrate · Endotherm · Primate | Modeling other minds; tool-making |
| Symbolic (humans) | Band · Settlement · City · Empire | Formal systems that still need people to interpret them |
| Digital (software) | Computer · Network · Model · Agent | — |

A waypoint is a point on the thread, not a description of every species in it. Which mechanisms an animal at that point runs, and which slots they sit in, is decided mechanism by mechanism.

Approximate dates for the animal line:
- **Bilaterian (~550 million years ago):** just before the Cambrian explosion.
- **Vertebrate (~420 million years ago):** the Devonian "age of fishes."
- **Endotherm:** about 200 million years ago in mammals, at the Triassic–Jurassic boundary. Birds became warm-blooded later and independently.
- **Primate (~66 million years ago):** the spread of mammals after the dinosaur extinction.

## 3. Rules for talking about evolution

A Darwinian process is any process with three features: members of a population vary; some variations leave more descendants than others; and descendants resemble their sources. Nothing in that definition is specific to biology.

Evolutionary language is easy to misuse. Four rules prevent the common mistakes.

- **Be clear what "selection" means.** "Selection" is a statistic: the correlation between what a member carries and how many descendants it leaves. No animal, organ or species does the selecting. The word "selector" may also name a mechanism inside an animal that chooses among options one level down, such as actions but not animals. Any other use of the word should be deleted.
- **Name what gets copied, or call it a correlation.** A claim that something evolved by selection must say what is being copied. If nothing is copied, the claim describes a correlation. That is worth reporting, but it does not explain anything. Evolutionary language can be fitted to any adaptive system, which is exactly why fitting it proves nothing.
- **Talk about costs, not payments.** Say what something costs in energy, risk or forgone alternatives. Never name a payer, a price or an exchange rate. A term is legitimate if it names a stock, a flow or a priority. It is not legitimate if it needs someone on the other side of a transaction.
- **Ask who benefits.** Wherever something seems to have evolved, ask who benefits from the trait being there. The answer identifies the lineage doing the evolving. If nothing benefits, nothing is evolving.

**Inner trial and error, and where bias comes from.** Brains let options be tested in imagination before the world tests them for real. Vision is a trial run of walking; thought is a trial run of action; the internal competition among candidate actions is a trial run of behavior. Any such inner test is necessarily biased, because it is a stand-in for the real test, and only a stand-in can drift from what it stands in for. The world's own test has no weighting beyond the outcome, so it cannot be biased.

Biases therefore live in mechanisms that estimate. The first such mechanism arrives with the animal line. The standards an animal's inner tests use are a fossil record of what killed its ancestors. Ancestral deaths set the coarse settings, such as innate alarms and what counts as rewarding. Learning during a lifetime tunes the fine settings on top.

**Ratchets.** An inner competition whose results are written back into memory gets better over time. Without write-back a competition only prunes, and every round starts from scratch. With write-back, today's outcome edits the store that produces tomorrow's options, and search becomes a path instead of a scatter. Inheritance is what stops the ratchet from slipping back.

**Every trial needs an ending.** For an attempt to count, it has to end: the organism dies, the action lands and produces an outcome, the conversation turn finishes, the program halts. In the animal line, the end of a trial and the moment of inheritance are the same: the outcome lands and the habit that produced the action is rewritten on the spot. That is why a body can learn in an afternoon what a lineage needs a thousand generations to learn.

**Maintenance versus defense.** Disturbances come in two kinds: those that cannot adapt to your response, such as erosion or weather, and those that can, such as predators, parasites and rivals. The first kind is met by maintenance: hold the standard and repair toward it. The second is met by defense, because the opponent changes its tactics in response to whatever you hold.

## 4. The four kinds of thing that get inherited

Each line of evolution has its own unit of inheritance, the smallest thing its test sorts. All copying works the same basic way: a store persists, and machinery reads it to produce new copies. The four units differ in where the store sits, whether it can leave the individual carrying it, whether that individual's experiences change it, how cleanly its trials can be counted, and how blind the variation is.

| | **Gene** | **Neme** (learned behavior pattern) | **Meme** (cultural item) | **Program** |
|---|---|---|---|---|
| What carries it and gets used up | The organism | A single performance of the behavior | A single telling | A single run |
| Where it is stored | The DNA sequence; walled off from the organism's experience | The learned habit in the brain; rewritten by experience | Brains, then writing; corrected toward familiar words at each retelling | Code; written deliberately and checked before release |
| How it is tested | Survival and reproduction | The outcome of the behavior | Whether people take it up and pass it on | Whether it gets run, kept, copied and relied on |
| What ends one trial | Death of the organism | The action finishes and its outcome lands | The telling ends and someone else takes the floor | The run finishes |
| What is scarce | A place in the population | Attention and the body's time | A turn to speak | Running time |
| How variation arises | Mutation and recombination, blind | Natural variability around the usual performance, blind but adjustable | Mistakes, recombination and innovation, partly directed | Edits and training, mostly directed |
| How faithfully it is copied | Very high | Low; rebuilt each time rather than copied from a template | Moderate | Perfect |
| How long it can last | Deep time | One lifetime, unless it borrows another channel | As long as people keep repeating it | Indefinitely |
| What it uniquely explains | Altruism toward relatives, DNA that does nothing, conflict among genes | Addiction; the habit that outlives its usefulness | Martyrdom, celibate clergy, earworms | Systems nobody can replace; malware |

What gets tested shrinks as evolution climbs. In the genetic line the test touches the whole organism. In every later line it touches a single act. From the animal line up, the store, the body housing it, and the act that gets tested are three separate things.

### The neme: the learned behavior pattern

**A neme is a learned behavior pattern that reproduces by being performed again.** It is stored in the brain, it is expressed as performances, and the consequences of those performances rewrite the stored pattern. Its copies are performances, its store is the physical memory trace (the engram), and its population is everything the animal does in a lifetime. Its fitness is how often it is performed. A behavior done once a day before it is rewarded and a hundred times a day after has multiplied, in the only sense multiplying ever has: more copies of the form, descended from fewer.

The three Darwinian ingredients, stated plainly:
- **What varies:** individual performances of the behavior, in form, timing and vigor. The amount of variation can itself be rewarded, so an animal's tendency to vary is a trait shaped by its own outcomes (Neuringer).
- **What tests it:** the outcome of the behavior, scored by the brain's reward-prediction signal.
- **What is copied:** the behavior pattern, from performance to performance, through a memory that is rewritten each time.

The neme is a weak copier compared with the gene. It is amplified through a memory store rather than copied letter by letter. That is a description of where it sits, not a flaw. The ratchet still works: variation keeps regenerating around the rewarded average, so learning accumulates. Anchors: Skinner's selection by consequences; Dennett on why the law of effect will not go away; McDowell's evolutionary theory of behavior dynamics, in which a population of behaviors reproducing under selection reproduces the matching law at the level of the individual animal; the dopamine reward-prediction error as the scoring signal.

**Attention is where nemes compete.** Because animals moved inheritance inside a single lifetime, they also had to move selection inside. Attention is the contest in which candidate behaviors compete to be expressed. Reward scores the winner, and consolidation writes it into memory. Attention is the animal's equivalent of a population's carrying capacity. This draws on biased-competition theory (Desimone and Duncan), global workspace theory (Baars; Dehaene), and William James's definition of attention as "taking possession of one out of several possible objects."

The contest has fixed capacity, so weight given to one option is weight taken from another. Losing options are not destroyed: an option that loses inside the brain is postponed, while an option that loses in the world is gone. In active inference terms, attention is the precision, or gain, given to prediction errors. That theory supplies the scoring rule for the contest; it does not say what competes or what persists.

"Attention" names two different things. Attention as a resource is the limited arena. Attention as a spotlight, meaning what the animal is attending to now, is just the visible result of whichever behavior just won.

**Where nemes begin.** A neme needs nerve tissue that can store new pairings the genome never specified, and replay them. Habituation and sensitization in a simple nerve net only turn up or down responses the genome already wrote. Genuinely new combinations arrive with associative learning in a centralized brain. That is why the neme starts at the Bilaterian waypoint, and why even simple associative learning already counts as one.

Reward-driven learning at the Vertebrate waypoint is the neme maturing, not being born. It matures again at Endotherm, from trial-and-error to an internal model. There, behavior is tested in imagination before the body is committed, which is Popper's phrase for letting your hypotheses die in your place.

**Two ways nemes travel.** Within a lifetime, a neme passes from the animal's past self to its future self through memory consolidation. This is the first line in which an individual inherits from its own past. Across generations, nemes pass through animal traditions: behavior learned socially by watching others, without any shared code. Traditions are the bridge the human line later builds language on.

On its own, a neme dies with its animal. It lasts longer only by borrowing another channel: genetic assimilation downward, where a learned behavior eventually becomes innate, or tradition and culture upward. The limit comes from the body, not from the neme. An animal is built by a body that keeps its germ line separate, and no pathway runs from a learned habit into eggs or sperm.

**What is not a neme.** Reflexes and instincts are not nemes, and the distinction is Skinner's before it is the framework's. Respondent behavior is triggered by a stimulus and shaped by the survival of ancestors. Operant behavior is emitted and shaped by its own consequences in this animal's life. Reflexes and instincts differ from each other only in complexity: a knee-jerk is a short, simple arc, while a fixed action pattern is a longer, sequenced program. Both are genetic. The line falls between behavior written by ancestry and behavior written by the individual's life, never between simple and complex.

**Two questions assign any behavior to its unit.** Where is its form stored? And which channel does its inherited variation travel through?

- **Yawning.** The form of a yawn is wired in during development. It appears before birth, across vertebrates, is generated in the brainstem, and is present even in infants born without a forebrain. Every answer says gene.
- **Contagious yawning** changes nothing. Contagion triggers an existing behavior; it does not copy a new one. Activation spreads, but no store is written.
- **Blink and wink.** These are physically almost identical. One is a reflex and the other is a move in a social game. History, not appearance, tells you which is which.

The layered cases are the instructive ones. An infant's cry is genetic in its form. Crying used strategically, shaped by what crying reliably gets, is a neme laid over the reflex and running the same muscles. Toilet training is a neme trained over a reflex, and the social norms around it are cultural items laid over the neme: three layers in one behavior. The Brelands' "instinctive drift" shows layers fighting in a training lab. Raccoons being trained to deposit tokens compulsively washed them instead, the inherited behavior bleeding through the learned one.

**Temperament is not the neme.** Temperament and correlated personality bundles are substantially heritable. They are the genes' reach into the animal's learning machinery: settings that bias which behaviors get learned. The neme is the learned behavior itself. This is the single most useful distinction a cross-species clinic can keep.

**Learning implies nothing about experience.** A spinal cord cut off from the brain can still learn and retain a reward-shaped leg movement (Grau). A neme needs storage, competition, write-back and a scoring signal. None of that machinery implies the animal feels anything.

**Clusters of learned patterns.** Nemes can bind into clusters. A cluster is a set of learned patterns that co-occur, trigger each other, and protect each other from extinction. Psychoanalysis described the object before the vocabulary existed: Jung's "feeling-toned complex," a cluster of associations around an emotional core that activates as a unit and resists dissolution. The modern anchors are stronger: Beck's schemas and their maladaptive forms in schema therapy; Bowlby's internal working model; and behavioral chaining, which describes how individual habits link into units.

"Who benefits?" has a clean answer here. The cluster's persistence serves the cluster: its members keep each other away from the situations that would extinguish any one of them alone. Transference is the cluster reproducing itself, the whole package re-enacted with a new person.

Two connections matter for a clinic:
- **Downward:** a behavioral syndrome (a heritable bundle of correlated traits) and a cluster of learned patterns have the same shape, but one is inherited and the other learned.
- **Upward:** a personality disorder is a maladaptive cluster of learned patterns grown on an extreme temperament setting during a sensitive period. Section 6 develops this.

**The disposable self.** The sense of self is to the learned repertoire what the body is to the genome. A body is the shared vehicle of a whole genome: it is maintained as long as it serves the genes and discarded while the genes go on. In the same way, the self is the shared vehicle of an animal's learned repertoire: built from it, spent in its service, and dissolved while the repertoire persists.

The self is specifically the vehicle of the imagining brain. Trial-and-error learning spends real performances. Once learning moves into imagination, an imagined trial needs an imagined actor: a protagonist who can absorb the imagined deaths so the body doesn't have to. That is why the self-model arrives at the Endotherm waypoint, where imagining arrives, and not before.

The self is disposable in three observed ways:
- It is spent in every imagined trial, dying in hypothetical futures all day long.
- It is switched off every night in sleep and rebuilt from memory each morning.
- It can go quiet under absorption, as in flow, while the body carries on at full capability.

The brain's self-referential machinery runs during planning and imagining and stands down during absorbed action. Switching it back on can wreck a skilled performance, which is what choking under pressure is. And the learned repertoire survives without it: an amnesic patient who could not remember a single practice session still improved across sessions.

### The meme, briefly

A meme is a cultural item copied from mind to mind. Its copies are tellings, and its fitness is how often it gets repeated, which is not the same as being true or being good for the people who carry it. Nothing physical passes between minds. A telling prompts the listener to rebuild the idea from their own material. That is the neme's mechanism running between bodies instead of within one, and animal traditions are the bridge between the two.

What the human line adds is escape. An idea that can jump from host to host outlives every host.

Two consequences matter for a clinic:
- **In the human line, the group is the unit,** not the person: the band, the village, the city, the empire. An individual person is where a cultural item rests between tellings.
- **Differences between people inside one group** come from the older layers showing through, plus each person's own settings on loops that only the group runs as a whole.

### The four kinds of mind

The philosopher Daniel Dennett described four kinds of mind, each learning in a new way. The framework maps them onto its lines:

| Dennett's kind of mind | How it learns | Framework line |
|---|---|---|
| Darwinian | By lineage survival | Genetic |
| Skinnerian | By trial and error | Nemetic, without a model |
| Popperian | By testing in imagination | Nemetic, with a model |
| Gregorian | With cultural tools | Symbolic |

## 5. The animal line, waypoint by waypoint

Each waypoint below lists every mechanism the comparative research places there, assigned to all seven slots. A waypoint is a point on one line of descent; a slot assignment is a fact about a mechanism, wherever it occurs. Each waypoint's mechanisms are laid on top of the waypoint before, and the older ones keep running.

The animal line's three drives:
- **Impetus** (doing): the drive to act and take risks, turning a sensed signal into committed movement.
- **Mastery** (holding a standard): the drive to get steadily better at one's own moves, a rising level of skill that holds across situations.
- **Autonomy** (learning): the drive to act from one's own inner map rather than from whatever is in front of one.

At the first two waypoints, two older drives still occupy the standard and learning slots. **Thrift** is the drive to run on as little energy as possible. **Interiority** is the drive to keep an organized inner state. Each is later overlaid by its animal-line successor and keeps running underneath. **Excitability**, the raw readiness of nerve tissue to fire, runs beneath every waypoint.

### The floor: Eumetazoa (~800 million years ago)

**Who is here.** Animals with differentiated tissues and a nerve net but no centralized brain: jellyfish, anemones, corals. Eumetazoa is the last waypoint of the genetic line, so it has the three cellular slots (doing, holding a standard, and the act-and-check loop) and no learning slot of its own. Its breakthrough is **whole-body coordination**: nerve tissue lets a body respond as one, fast. That coordination is not communication in the shared-code sense; it is what the animal line is later built from.

It serves as a clinical floor because what fails here is a setting of excitability, a state, or a fixed program, never learned content.

- **Doing:** **Persistence**, the drive to keep a pattern going, which at its high end is dormancy; **Excitability**, the raw readiness of nerve tissue to fire; **Reflex repertoire**.
- **Holding a standard:** **Homeostasis**, holding internal state at a setting the body fixes; **Thrift**, running against an energy floor; **Chronotype**, when active hours fall, kept by an internal clock; **Sensory adaptation**, resetting a sensor's operating point so it answers to differences rather than absolute levels; **Aging type**, how damage accumulates against repair.
- **Act and check:** **State gating**, switching among stored programs as conditions change; **Allostatic regulation** in its first form, sleep homeostasis; **Home style** and **Pruning style** in their first forms.
- **Turning a response up or down:** **Non-associative learning** (habituation and sensitization). It changes the gain on a response the genome already wrote, not the content of the response, so a failure here is a failure of a setting.
- **Interiority**, the drive to hold an organized inside, runs beneath all of these.

### Bilaterian (~550 million years ago)

**Who is here.** Animals with a head and a tail, a left and a right, and a brain at the front where the senses gather. Worms, insects, snails, fish and people all share this body plan.

**The breakthrough: Attention.** A contest in which candidate movements compete to be expressed, coupled to a memory that scores the winner and keeps it. The contest and the keeping form one breakthrough, because a contest whose results are not written back only prunes. This is selection moved inside one animal, and it runs at every waypoint from here up.

**Doing (Effector)**
- **Impetus.** The readiness to approach, explore and act when nothing threatens. Already a measurable trait in the simplest brains. A roundworm with 302 neurons comes in bold and shy versions: the same individuals cross a barrier toward a tempting smell, trial after trial, while others hold back. *Stern et al. 2017, Cell, doi:10.1016/j.cell.2017.10.041.*
- **Excitability.** The raw readiness of nerve tissue to fire and react. Every later behavior is built on top of it.
- **Reflex repertoire** (from Eumetazoa). The built-in set of wired movements, fired the same way every time, with nothing learned and nothing checked: a jellyfish's swim pulse, a worm's rapid withdrawal from a poke, a startle that snaps the body away. These run underneath whatever the animal learns on top.

**Holding a standard (Regulator)**
- **Thrift.** Nerve tissue is the most expensive tissue an animal carries, gram for gram. A bilaterian concentrates its nerve tissue at the front where the sensing happens instead of spreading it evenly, because a net costs more than a cord to do less. The standard held is an energy floor.

**Learning (Modeler)**
- **Interiority.** A faint inner state, such as hunger or arousal, that colors how the animal reads the world and marks whatever was around when things went well or badly.
- **Pruning style** (from Eumetazoa, as developmental cell death). A developing nervous system builds far more connections than it keeps, then eliminates the ones that carry little traffic. Animals differ in how actively they prune. *Riccomagno & Kolodkin 2015, doi:10.1146/annurev-cellbio-100913-013038.*
- **Remembering style: write rate and lock strength.** How quickly an experience is written into the store, and how firmly it locks once written. Some content locks after one trial and resists revision; other content stays open. This is the learning gate, set separately for each kind of outcome, so an animal can lock fears fast while its appetitive learning stays ordinary.
- **Orienting style.** Which cue an animal credits when something good or bad happens: the most recent cue, or the unfamiliar one. Cues the animal has met many times without consequence become background and are hard to learn about later (latent inhibition). How strongly this happens is a setting on how the store is updated.

**Act and check, no learning (Controller)**
- **Affect.** How an animal's inner state runs, on two axes: good to bad, and calm to aroused. Even a roundworm has both, which is the bare scaffolding of mood. The error a steering animal corrects against is felt, not measured. *Stern et al. 2017.* Affect has two settings that vary between individuals: its **threat side**, how strongly threat registers, which is general fearfulness of novelty, noise and strangers; and its **dynamics**, how fast it rises and how fast it returns to baseline, which is lability. In ratings, lability is often seen through the uninhibited actions it produces, so it is best measured directly, by time to recover after a standard challenge.
- **Steering.** Pointing the whole body at a goal and closing on it, or turning and fleeing. It needs a front end where the senses gather. A jellyfish an inch from food can lose it; a worm with a head does not. *Bennett 2023, A Brief History of Intelligence.*
- **Inhibition.** Holding a strong default back instead of firing it. A crayfish has a giant nerve cell that flips the whole body backward in a fraction of a second when startled, and a layer of inhibition decides when not to fire it: mid-meal or mid-swim, the escape is held. *Edwards et al. 1999, doi:10.1016/S0166-2236(98)01340-X.*

**Forecast and pre-correct (Budgeter)**
- **Allostatic regulation** (from Eumetazoa, as sleep homeostasis; prediction from a learned model is the Bilaterian addition). Holding different normal states for different situations, set by prediction rather than fixed. A brainless jellyfish already sleeps and sleeps deeper after deprivation (Nath et al. 2017). A fruit fly sleeps in the full sense: it is less active, harder to rouse, and sleeps harder after a night kept awake. *Shaw et al. 2000, Science, doi:10.1126/science.287.5459.1834; Sterling on allostasis.*

**Act and learn, no standard (Connector)**
- **Temperament.** A standing bias in how an animal acts, stable across days, linking what it does to its inner state. Bold worms and shy worms share the same genes and the same 302 neurons, yet each keeps its own foraging style. *Stern et al. 2017.*
- **Associative learning.** Learning that one thing predicts another. A sea slug touched on the siphon and shocked on the tail soon yanks its gill hard at the touch alone. Eric Kandel traced this to changes between named neurons. *Hawkins et al. 1983, Science, doi:10.1126/science.6294833.*
- **Home style** (from Eumetazoa, where an anemone is anchored for life and a jellyfish drifts with no home). The kind of place an animal keeps. Early bilaterians range from burrowers that hold a fixed tunnel to wanderers that carry no home at all. Where the animal settles is driven by what it has learned about where it has been.

**The contest (Workspace)**
- **Attention.** As above: candidate movements compete for one body, the outcome is scored, and the memory that produced the winner is rewritten. Steering plus affect produces associative learning. Associative learning makes future steering more rewarding, which favors finer steering and richer affect. *Bennett 2023.*

### Vertebrate (~420 million years ago)

**Who is here.** Animals with a backbone and a skull around a larger brain: fish first, then everything descended from them, including amphibians, reptiles, birds and mammals.

**The breakthrough: Reinforcing.** A brain that can work out which of its recent actions earned a reward that arrived seconds later, and tune toward it. The machinery is the basal ganglia, nearly unchanged from the lamprey to the human. Every animal that can be trained with food rewards runs this circuit.

**Doing (Effector)**
- **Impetus.** Put something new in a tank and fish sort into two groups: one noses straight up to it and owns the corner, another hangs at the back and watches. Bold and wary, repeatable across weeks: the fish that explored the new object this week explores it next week too. *Bell et al. 2009, Animal Behaviour, doi:10.1016/j.anbehav.2008.12.022.*
- **Excitability.** The raw readiness to fire, now running through a centralized brain and spinal cord.

**Holding a standard (Regulator)**
- **Mastery.** The drive to get steadily better at one's own moves. The standard held is the expected outcome, and dopamine neurons report how far reality departs from it. They fire above baseline when a reward beats expectation, below when it falls short, and shift that signal back onto the earliest cue that reliably predicts the reward. *Schultz, Dayan & Montague 1997, Science, doi:10.1126/science.275.5306.1593.* Mastery carries two settings that vary between individuals: **frustration tolerance**, how strongly the animal is upset when an expected reward falls short or a goal is blocked (Amsel's frustrative nonreward), and **tolerance band**, how small a departure from the expected outcome already counts as a shortfall. A tight band combined with habit dominance is the animal form of rigid perfectionism.

**Learning (Modeler)**
- **Interiority.** A richer inner state: a gut that senses its own contents, and an inner economy of hunger, stress and energy that the brain reads and weighs.
- **Orienting style.** In vertebrates, both sides of the setting run through the same dopamine and basal-ganglia circuit. The machinery that stamps in the freshest cue is the same machinery that screens out a familiar one. Give a fish days of exposure to a harmless cue and it is slow to learn when that cue finally predicts something. How slow is the setting.

**Act and check, no learning (Controller)**
- **Coping style.** How an animal meets stress, on a dial from proactive to reactive. Proactive animals hold territory, build bold fixed routines and get used to things fast. Reactive animals freeze, stay wary and stay flexible. The split depends on the balance between the fast stress system (the sympathetic nervous system) and the slow one (the stress-hormone axis), with dopamine coupling the two. It is replicated in rodents, birds and fish. *Koolhaas et al. 1999, doi:10.1016/S0149-7634(99)00026-3.* Coping style is *how* an animal meets stress; how *strongly* it reacts is a separate setting (the threat side of Affect). The two vary independently (Koolhaas et al. 2010, the two-tier model).
- **Behavioral syndrome.** The way an animal's settings correlate across situations. Measure boldness, activity and aggression in individual fish and they travel together: the bold ones are also the active, aggressive ones. The links are weak but consistent enough for evolution to act on the whole bundle, and for other animals to read. *Sih, Bell & Johnson 2004, doi:10.1016/j.tree.2004.04.009.*
- **Procedural memory.** Stored movement programs on autopilot. A goldfish that learns a maze eventually swims it without working through each turn. This is the same kind of memory behind a bird's song or a person riding a bicycle, held in the basal ganglia and cerebellum from sharks to humans. *Squire 2004, doi:10.1016/j.nlm.2004.06.005.*
- **Approach drive.** When a vertebrate sees something good, dopamine neurons deep in the midbrain fire and pull it toward the thing. The same pathway runs in a guppy, a guinea pig and a person, and individual fish differ in how strongly it drives them. *Wise 2004, doi:10.1038/nrn1406.*

**Forecast and pre-correct (Budgeter)**
- **Gut sense.** A second nervous system lining the gut, with about 500 million neurons in a human (more than the spinal cord). It monitors food and chemistry and sends forecasts up to the brain, shaping mood and energy in ways the rest of the brain never sees directly. *Furness 2012, doi:10.1038/nrgastro.2012.32.*
- **Pace of life.** How fast an animal grows up and lives out its life, from fast-and-furious to slow-and-steady, regulated against the expected pace of its life history. The prediction that bold animals also develop fast holds weakly at best at the level of individuals. *Royauté et al. 2018, doi:10.1007/s00265-018-2472-z.*

**Act and learn, no standard (Connector)**
- **Temperament.** The bold-or-wary axis, stable across time. *Bell et al. 2009.*
- **Home style.** Some fish defend a fixed territory or nest site for a season; others shoal and roam open water, keeping no home at all.

**The contest (Workspace)**
- **Reinforcing.** The actor–critic arrangement: one part of the circuit selects actions, another evaluates outcomes, and the reward-prediction error updates the selector. *Sutton & Barto; Bennett 2023.*
- **Temporal credit.** Linking an action to a reward that arrives seconds later. A fish bumps a lever, food drops three seconds later, and by then it has done six other things. Dopamine solves this by shifting its signal back onto the action that earned the reward. *Schultz et al. 1997.*

### Endotherm (~200 million years ago in mammals; later and separately in birds)

**Who is here.** Warm-blooded animals: mammals and birds. They have extended parental care, sleep that consolidates memory, and many new brain regions layered over the older vertebrate brain. Endotherm is a grade, not a single lineage, because mammals and birds arrived here independently.

**The breakthrough: Simulating.** Running the inner model of the world offline, playing out an action as if on a screen before the body performs it. The episodes it runs are ones the animal never actually had: the model generates cases instead of only storing them. This is the waypoint where the imagining brain arrives, and the self with it.

**Doing (Effector)**
- **Impetus.** A measurable, repeatable trait: some rats reliably explore an open, exposed space while their cage-mates will not leave the walls. *Sih, Bell & Johnson 2004.*
- **Excitability.** A startled animal's instant freeze or bolt.

**Holding a standard (Regulator)**
- **Mastery.** A rat refining its run through a familiar maze, faster and surer each trial.

**Learning (Modeler)**
- **Autonomy.** The drive to act from one's own inner map rather than from what is in front of one.
- **Remembering style.** What the model keeps and what it lets fade, now actively curated offline. In a resting rat, place cells (neurons that fire for particular locations) replay recent routes, fixing some into lasting memory while others decay. *Foster & Wilson 2006, Nature, doi:10.1038/nature04587.* Anchors: Kahneman's remembering self.
- **Orienting style.** Now tied to context. Brain machinery tags where a cue was met, so a cue that has faded to background in a familiar room regains its pull when the room changes. Animals differ both in where the setting sits and in how tightly it is bound to place.

**Act and check, no learning (Controller)**
- **Coping style.** Rodents sort cleanly into proactive and reactive copers, and each style holds across situations. *Koolhaas et al. 1999.*
- **Behavioral syndrome.** Rodents score high or low together on boldness, aggression and exploration, across contexts and over time. *Sih, Bell & Johnson 2004.*
- **Autonomous mind.** Running on the expectations already held, so that new outcomes do not rewrite them. Blocking shows the mechanism: once a rat has learned that one cue predicts a shock, a second cue paired with the same shock gains no power of its own, because the existing expectation leaves nothing to learn. *Kamin 1969.* Countercontrol is the same thing socially. The animal's existing model keeps a trainer's new contingencies from taking hold, and novel cues the trainer introduces meet avoidance. It is documented across mammals and birds, and is underrepresented in lab work because standard operant chambers exclude the social loop it needs. *Delprato 2002.* Anchor for the term: Stanovich 2011, Rationality and the Reflective Mind.

**Forecast and pre-correct (Budgeter)**
- **Attachment security** (in humans, one root of neuroticism; general fearfulness, the threat side of Affect, is the other). Bowlby described a behavioral system whose goal is the availability of a caregiver, with Ainsworth's secure base as the standard. The caregiver is an internally modeled figure whose predicted availability has consequences for the body. A secure model settles quickly. An insecure model holds the possibility of absence close. Animals differ in how readily an ambiguous signal near the caregiver reads as a threat. Attachment runs on the same brain machinery that forecasts the body's needs: deep cortical regions sending predictions to the hypothalamus, brainstem and spinal cord, with the sensing of internal body states as the basis of emotion. *Bowlby; Ainsworth; Barrett & Simmons 2015; Seth 2013; Adams, Shipp & Friston 2013.*

**Act and learn, no standard (Connector)**
- **Latent learning.** Learning with no reward. Rats allowed to wander a maze with no food build a map anyway, then beat reward-trained rats the moment food appears. *Tolman 1948, doi:10.1037/h0061626.*
- **Affiliation.** The pull toward specific other individuals, and how much their state moves the animal's own conduct. Other animals are now in the model as particular individuals whose presence is valued. Prairie voles form lasting pair bonds and console a distressed partner (Burkett et al. 2016, Science); rats free a trapped cagemate even when chocolate is on offer (Bartal, Decety & Mason 2011, Science). Affiliation has two settings that vary separately: its **pull**, how much the animal seeks and values particular others, and its **distress responsiveness**, how much another's distress moves the animal's conduct. Responding to a distressed partner has its evolutionary root in parental care, but the setting is general. Low pull is social detachment. Low distress responsiveness, whatever the pull, is the callous core of antagonism: an animal can be sociable and callous at once. In dogs, domestication selected this setting toward humans, and what dog-personality research reports as agreeableness or sociability is Affiliation's setting.
- **Self-model.** The inner model now includes the animal itself. A rat that tracks its own uncertainty, and declines a test it is unsure of in favor of a smaller guaranteed reward, is reading a model that includes its own states. *Foote & Crystal 2007, Current Biology, doi:10.1016/j.cub.2007.01.061.*
- **Algorithmic mind.** Running a chain forward from a starting point: trying the route in the model, then acting. At the mouth of a maze it knows, a rat's place cells fire down the route it is about to take, ahead of its body. *Pfeiffer & Foster 2013, Nature, doi:10.1038/nature12112; Stanovich 2011.*

**The contest (Workspace)**
- **Simulating.** Replay forward and in reverse while the body is still, rehearsing sequences off the clock. The imagined trajectories feed back into the model that proposed them. *Pfeiffer & Foster 2013; Foster & Wilson 2006; Bennett 2023.*
- **Reflective mind.** Stepping back to check one's own thinking: candidate actions are rehearsed against a standard and the model before anything is committed. *Stanovich 2011.*
- **Temporal credit.** As at Vertebrate, now with dopamine shifting its signal back onto the earliest cue that reliably predicts a reward. *Schultz, Dayan & Montague 1997.*

### Primate (~66 million years ago)

**Who is here.** Lemurs, monkeys, apes and humans. They have grasping hands, forward-facing eyes, and an outer brain layer expanded for life in complicated social groups.

**The breakthrough: Mentalizing.** Holding a model of another mind: what it knows, wants and does not know. Another animal's mind cannot be opened, and modeling it from outside is this waypoint's answer to that problem. Nothing here involves a shared code. Grooming, appeasement, alliance signals and displays all pass between animals that carry models of one another.

**Doing (Effector)**
- **Impetus.** Plays out socially as much as physically: who approaches a tense situation, who challenges a rival, who hangs back and watches.

**Holding a standard (Regulator)**
- **Mastery.** A young chimp spends years getting good at cracking nuts or fishing for ants, practicing long past bare competence.

**Learning (Modeler)**
- **Autonomy.** A rich model of the world and of one's place in it, acted on even against the immediate pull of the group.
- **Triadic awareness.** Keeping track not just of one's own rank but of who outranks whom and who allies with whom across the whole group, and updating that map from what the animal sees. A chimp registers not only that the alpha changed but that everyone present saw it change. One public submission grunt, witnessed by all, has split a troop along a new fault line and led, years later, to lethal raids. *Cheney & Seyfarth 1990, 2007.*

**Act and check, no learning (Controller)**
- **Coping style.** The same split runs in primate troops as in fish and rodents: bold confronters who get used to things fast, and wary watchers who stay vigilant. *Koolhaas et al. 1999.*
- **Autonomous mind, social form.** Running on what the group already does. Teach two chimp troops different ways to crack the same nut, then show each an expert using the other way: they watch, understand, and keep doing it their own way. *Whiten et al. 2005, Nature, doi:10.1038/nature04047.*

**Forecast and pre-correct (Budgeter)**
- **Attachment security.** Carried forward, with more to read: a shifting coalition offers far more ambiguous signals than a solitary forager's world did.
- **Sociometer.** An inner gauge of how accepted or valued one is, read from others' regard. When inclusion is threatened the gauge falls and prompts corrective action, and social rejection recruits the same brain circuitry as physical pain. Dominance appears as its own separate personality dimension in every non-human primate measured. *Baumeister & Leary 1995; Leary; Eisenberger; King & Figueredo 1997, doi:10.1006/jrpe.1997.2179.*

**Act and learn, no standard (Connector)**
- **Self-model, social form.** A monkey does not only know it lost a fight; it knows the others watched it lose, and marks its own worth down by what the watchers now think. *Foote & Crystal 2007.*
- **Affiliation, coalition form.** The pull toward specific others, now aimed by a model of what each of them knows and intends. It shows in grooming, alliances and friendships lasting years, each requiring a running account of who allies with whom and what each intends. In chimps, a gene tied to social bonding (the same one linked to pair bonds in voles) predicts how strongly an individual affiliates. *Hopkins et al. 2012, doi:10.1111/j.1601-183x.2012.00799.x.*
- **Agreeableness.** How warmly an animal handles others, from tolerant and cooperative to pushy and combative: how far another's modeled *wishes* move its own conduct. Modeling what another wants is what puts this construct at Primate; its older root is Affiliation. It is a measurable, stable personality dimension in chimpanzees and bonobos. *King & Figueredo 1997.*
- **Tactical deception.** Pursuing a goal by managing what others know. Facing food and a dominant rival, a subordinate chimp goes for the piece the dominant cannot see. *Hare, Call & Tomasello 2000, doi:10.1006/anbe.2000.1518.*

**The contest (Workspace)**
- **Mentalizing.** A low-ranking chimp wanting food the boss is sitting on notices that the boss cannot see behind a rock, and takes the long way into the blind spot. *Bennett 2023.*
- **Standing.** Weighing one's position relative to others before acting. Show a capuchin monkey her partner getting a grape for the same task that earns her a cucumber slice, and she throws the cucumber back. She is acting against a standard of fairness held relative to a modeled peer, not against hunger. *Brosnan & de Waal 2003, Nature, doi:10.1038/nature01963.*
- **Certainty.** How much evidence an animal needs about another before betting on them. There is no way to find out whether an ally will return a favor except by doing one first, so the bet always comes before the evidence. Some chimps groom a new partner once and back them in the next fight. Others need years of small exchanges before they will stand beside anyone, and a few never do. The coalition-builder and the loner are two ends of one setting, not two kinds of animal. Anchors: Trivers on reciprocal altruism; Frank on commitment.

### Constructs that belong to the human line

Identity, self-construal, social norms and narrative selfhood need a shared code: a self described in a group's terms, or a rule held in common and enforced by others. No animal on the thread has one, so these are human-line constructs and appear in animals only through human report. The nearest animal constructs are the self-model in its social form (an animal that knows it was watched losing), Standing (acting against a held expectation of fair treatment relative to a peer), and Triadic awareness (a map of the group's relationships). A household rule a dog has learned is learned content, not a norm.

### Shared codes off the thread, and two pet cases

A mechanism that passes a function's test belongs to that function wherever it occurs, including in lineages that branched off the thread. But a function found off the thread was not born from the lineage that carries it in the same way.

- **Songbirds.** Their song passes every part of the shared-code test. A tutor is required, the young bird reproduces the song, and its syllables are corrected toward the tutor's standard forms.
- **Humpback whales.** Their song shows the strongest population-wide conformity in the literature.
- **Dolphins.** They copy one another's signature whistles and use them as names.

What stays small in these cases is range. A song directs no hand, so nothing the song produces is left in the world. The loop it closes runs through other animals and never through objects.

**Alex the parrot** was a vocal learner who reproduced words and corrected toward their standard forms, using a code he learned from people who already used it. This is one animal using a shared code, with no population of users and no tradition. An assignment describes what an individual does, not the history of its species, so a single animal can pass.

**Dog soundboards.** The dog does not produce the word; the button does. The distinct units are engineered into the device rather than corrected toward by the dog, and the dog learns the button–outcome connection by association. The dog does not have a shared code. The communication is real, but it is done by the device and the owner: a human's shared code extended over the dog, with the dog acting inside the human's loop.

## 6. How the stack fails

### Three kinds of failure

Failures sort by the stage of evolution that built the failing machinery.

| Stage | Name of failure | What fails |
|---|---|---|
| Genetic | **Disease** | Cells, tissues and organs no longer maintain stable internal conditions |
| Animal | **Disorder** | The learning machinery, or what it has learned, no longer serves the animal and cannot set itself right |
| Human | **Disorganization** | Cultural, institutional and normative structures no longer regulate a group's shared life. Durkheim's anomie; Shaw and McKay's social disorganization |

A single animal can carry any failure its stages allow. A dog with cancer and a learned fear has a genetic-stage failure and an animal-stage failure in the same body.

Each stage has one characteristic failure in common with the others: a stored pattern that has escaped the test its stage normally applies. At the genetic stage it is cancer and selfish DNA, cell lineages and sequences that succeed while the organism fails. At the animal stage it is addiction and insulated clusters of learned patterns. At the human stage it is ideas that spread at their carriers' expense, and institutions and systems locked in because removing them costs too much. Escape is not every failure at any stage. Infection is a different lineage succeeding, injury and degeneration are wear, and many animal-stage disorders are failed settings or states. But escape occurs at every stage, in the same form, and it grows more elaborate as each line matures, scaled by how well the escaping pattern can model its own test. Selfish DNA models nothing. Cancer evades the immune system, a crude model of its tester. Avoidance keeps away from the test. An insulated cluster in a warm-blooded animal forecasts the test and recruits the body's forecasting to make the test too costly to run.

**Stores fail; units don't.** When a pair or a group is in trouble, the failure is located in whichever member's store has become insulated, not in the pair or group as a whole. Two animals' patterns can each serve as the other's circumstances, coupled but not shared. A store genuinely held between individuals is a shared code, which no animal on the thread has; even there the failure sits in a store, one level up.

Failures are also described from a higher stage than the one they live in: disease is sensed by the animal through internal body sensing and described by people through medicine, and disorder is described by people through psychology and psychiatry. The stage that describes a failure is not the stage where it lives.

### What makes a disorder: harmful dysfunction

Learning normally corrects itself. A learned behavior that stops paying off is scored down, performed less, and rewritten. That is the ratchet working, and a poor fit between an animal and its circumstances is not, on its own, a disorder.

**An animal-stage disorder is a harmful dysfunction of the learning machinery or of what it has learned.** Two things are required:

- **Harm.** The pattern damages the animal's welfare or functioning, raises its risk of death, injury, relinquishment or loss of freedom, or harms others. A behavior is not its own harm; its consequences are.
- **Dysfunction.** Either a setting of the machinery has stopped working, or learned content has lost its ordinary ability to be corrected.

**Loss of correctability is how dysfunction of learned content shows itself.** It is evidence, not the definition, because some resistance to correction is healthy. Conditioned taste aversion is learned in a single trial and built to resist extinction, and that is adaptive: the next test could kill. Blocking, commitment and persistence are valuable for the same reason. Insulation without harm is not a disorder; a costless superstitious ritual is normal behavior. Insulation becomes clinical when harm attaches to it, often through a fault of onset: a taste aversion mis-credited onto a staple food, causing weight loss, is insulation working as built on the wrong target.

**"Ordinary contact" means opportunities, not completed trials.** Treatment corrects disorders, so a disorder cannot mean "uncorrectable by anything." It means uncorrectable by the opportunities the animal's everyday world presents. Those are counted whether or not the animal takes them. The stairs are there every day; a dog that leaves before the outcome lands is showing the insulation, not missing the test.

**Treatment supplies the missing opponent.** An insulated pattern is one that has lost its opponent: the world no longer gets to end its trials. Treatment brings the world back in as the party that ends the trial, so the outcome is scored. Exposure, response prevention, and reintroducing activity that has stopped are each a version of that move.

**Who benefits tells adaptation, mismatch and disorder apart.** A learned behavior pattern's fitness is how often it is performed. The question is where that fitness comes from.

| Where the pattern's fitness comes from | What it is |
|---|---|
| Outcomes that are good for the animal | **Adaptation** |
| The current circumstances, such as a keeper's attention that reinforces a problem behavior | **Mismatch.** Change the circumstances and the pattern extinguishes |
| A source inside the animal's learning machinery that the world's outcomes do not reach: other learned patterns protecting it, its own self-generated reward, or a reward signal that has drifted away from welfare | **Disorder.** Change the circumstances and nothing happens |

This is also what duration criteria in psychiatric manuals are quietly measuring. Requiring a pattern to last for weeks or months asks whether it has survived long enough under ordinary life that it is not going to correct itself. The test is sharpest when the clock is set by opportunity:

- **For a pattern that answers a deficit,** the clock starts once the deficit is corrected.
- **For a pattern tied to a cue,** the clock starts at the first ordinary encounter with the cue, whether or not the animal stays to complete the trial.
- **For a pattern caused by a medical condition,** the clock starts once the condition is corrected. If the pattern then remits within the typical period, it belonged to the medical condition.

### Two kinds of evidence: settings and content

The learning machinery has **settings** and it has **content**.

- A **setting** is a parameter of the machinery: how strongly reward registers, how hard the brake on a default response engages, how quickly arousal rises. Settings are fixed by genes and by sensitive periods, and they are not rewritten by any single experience. They can drift under sustained load: adult stress-hormone set points shift with chronic adversity, which is what allostatic load means. Drift is a state writing a trait at the level of settings, and it ratchets: each episode of load can lower the threshold for the next (the kindling or sensitization account of recurrent depression, Post 1992). The animal recovers but is more vulnerable next time, so recurrence and remission belong in the record.
- **Content** is what the machinery writes: learned patterns, and clusters of learned patterns that protect one another.

Both can fail, and both fit the definition above, by different routes.

- **A failed setting** cannot be corrected by ordinary contact because settings are not what everyday learning rewrites; at most they drift back slowly once load lifts. The evidence for it is a **marker measured outside the behavior itself**: a physiological reading, a test of the mechanism, a response that should occur and does not.
- **Failed content** has become insulated from correction it could in principle receive. The evidence for it is **persistence under ordinary contact**.

One setting deserves its own name: the **learning gate**, which decides which content locks after a single trial, which stays open to revision, and when developmental windows close. Conditioned taste aversion is the gate locking by design. The gate is how an older store sets write permissions on a newer one, the same move as the wall that keeps experience out of the genome. It is a facet of remembering style, not of orienting style: orienting style decides which cue gets the credit, while the gate decides how fast the credit is written and how firmly it locks. The gate is set separately for each kind of outcome. Mice selected for fast fear learning changed in aversive learning only, so the setting is not a single number for the whole animal. Its evidence is the evidence for any setting: acquisition and extinction rates on a standard probe, run per outcome domain. A fear that locks as if it were a taste aversion is a gate failure; so is its mirror, an animal that keeps eating what made it sick. Avoidance is not a gate failure: the gate is open, and the animal never goes where the test happens.

A setting at an extreme is not, by itself, a disorder. A reactive coper or a highly reward-sensitive animal is a variant, not a patient. An extreme setting is a **predisposition**. It becomes clinically relevant when it pushes the learning machinery into one of the ways of getting stuck described below, or when the setting has stopped working at all rather than sitting at one end of its normal range.

The two kinds predict different courses:

| | Settings | Content |
|---|---|---|
| Onset | Early | After an identifiable history |
| Across contexts | Stable | Tied to particular contexts |
| Inheritance | Substantially heritable | Learned, sometimes socially transmitted |
| Response to relearning | Weak | Strong |

Many clinical presentations are both at once. The personality disorders are the clearest case: **a cluster of learned patterns grown on an extreme setting during a sensitive period.** That is why they look trait-like and learned at the same time. Separation-related distress in dogs is probably the same shape: a vigilant setting for reading attachment cues, with a cluster written on top of it after a move or a change of schedule.

### How correction fails

When learned content becomes insulated, it happens in one of five ways. The first three are failures of one function inside the reinforcement loop; the last two are failures of the loop's shape.

| Way of getting stuck | What fails | Example |
|---|---|---|
| **Non-sampling** | Doing: the animal stops acting, so nothing gets scored | Withdrawal and lost interest, where rewards that return go unnoticed because nothing goes out to meet them |
| **Mis-scoring** | The standard: the reward signal has drifted away from welfare | Addiction |
| **Closed seam** | Learning: the plasticity that could rewrite the pattern has closed | An undersocialized dog whose sensitive period ended with the setting locked in empty |
| **Self-shielding** | The loop: the pattern keeps the animal away from the test | Avoidance: the dog never stays long enough to learn the stairs are safe (Mowrer's two-factor theory). Blocking and countercontrol work the same way |
| **Self-scoring** | The loop: the behavior produces its own outcome, so the world never grades it | Stereotypy, a closed loop with no contact with the world |

**Each stage of the animal line adds a new way to get stuck.**

| Stage | New way to get stuck | Example |
|---|---|---|
| Bilaterian | Associative avoidance; cues tuned out as background; Pavlovian responding that no longer answers to the outcome | Fruit flies keep seeking ethanol through bitter quinine and electric shock; crickets keep responding to a cue after its reward has been devalued; cockroaches made helpless carry it to a new task. Each is shown within a single session, so persistence across days in invertebrates is unestablished |
| Vertebrate | Habit capture of actions: a learned routine of instrumental behavior that no longer answers to its result | Insensitivity to outcome devaluation, the cleanest laboratory marker of a habit |
| Endotherm | Imagined trials that never end | Forecasting danger without ever testing it; worry as rehearsal with no outcome to write back |
| Primate | Models of other minds that can never be disconfirmed | Another animal's intentions are never directly observed, so a hostile reading fits every ambiguous act |

**Forecasts that shield themselves.** The body's forecasting system, which corrects before a problem arrives, can get stuck the same way avoidance does. In illness the body forecasts scarcity and cuts spending: less movement, less exploration, less interest. That is ordinary sickness behavior. The cut also stops the sampling that would disconfirm the forecast, so the forecast protects itself from its own test. The predicted course is load first, then a drop in reward sensitivity, then withdrawal that locks the state in. Depression-like states that follow illness should persist after physical recovery more often when the animal's surroundings give it little reason to start sampling again.

**Clusters can recruit the body's forecasts.** In panic, the body's own arousal becomes a learned cue that predicts danger, so the forecast makes approaching the feared situation aversive (Bouton, Mineka & Barlow 2001). The kept-animal case is pre-departure arousal in dogs: keys and coat trigger physiology before the keeper leaves, and that physiology makes the calm departure that would correct the pattern costly to undergo. The forecasting system becomes the cluster's enforcer.

### How a pattern gets written

Correctability concerns why a pattern persists. How it was written is a separate question, and the two should be recorded separately.

| Route of onset | What happens |
|---|---|
| **Over-writing** | A single overwhelming trial writes the pattern too strongly. If every fear writes in one trial, across unrelated events, the fault is in the learning gate, a setting, not in the onset |
| **Mis-crediting** | The outcome is credited to the wrong cue, or generalizes too broadly |
| **Writing under load** | The pattern is learned while pain, illness, exhaustion or a new environment has pushed the animal into an older state |
| **Deficit-induced** | The pattern is a response to a standing lack in the environment |

A pattern written by any of these routes that then corrects normally is a proportionate response, not a disorder. It becomes a disorder only when one of the five ways of getting stuck keeps it in place. Prediction: onset histories of chronic disorders will over-represent learning under load.

### Eclipsing: when the top layer goes quiet

Behavioral tendencies are layered in the order evolution laid them down, and each has a setting, like a volume knob.

**The low end of a tendency is not a smaller amount of it. It is the tendency switched off, with the older layer underneath showing through.** At the low end the newer layer goes quiet and the animal falls back on the layer beneath, behaving as its ancestors did before the newer layer existed.

This differs from the usual evolutionary view of personality, associated with Daniel Nettle, which gives each personality dimension real costs and benefits at both ends and treats the dimensions as a flat set. Here the dimensions sit on a deep stack of older tendencies, and the cost found at the low end is the signature of the older layer. DeYoung's Cybernetic Big Five Theory already treats personality dimensions as settings of a regulating system; the framework adds the evolutionary order of the layers.

What shows through depends on which function went quiet. When a standard-holding layer goes quiet, a push drops out (the gain on reward, for example) and the action falls back to the older layer. When a learning layer goes quiet, the low end is absorption: the self-model that would narrate the moment goes quiet while the animal acts at full capability.

**Load is the body's energy budget.** Under load, layers go quiet from the top down, most recently evolved first. The load is not a separate stress variable but a stock the body has tracked since the earliest cells: energy gathered and not yet spent. Every evolved layer is a standing draw on it, and when it runs short the draws are cut from the top down. An animal running short does not become a smaller version of itself. It becomes an older one. One stock covers hunger, exhaustion, illness and acute stress. *Sterling and Eyer on allostasis; Barrett on body budgeting.*

**Eclipsing is a state, not a disorder of learned content.** It should resolve when the load does; delirium belongs here. What turns a state into a lasting problem is what the animal learns while eclipsed. Pain-driven guarding written into the repertoire can outlast the pain: a state writes a trait.

### Performing a behavior is not the same as keeping it

Whether a behavior is expressed and whether it is retained are controlled by separate gates. A behavior can be performed, rewarded, and still not be retained, because memory consolidation is a separate step that runs offline during sleep. Disrupted sleep therefore matters for kept animals beyond fatigue: it decides what the day's experience writes.

### Medication and relearning

Medication can change settings and can reopen plasticity. Selective serotonin reuptake inhibitors, for example, can restore a juvenile-like capacity to rewire in adult cortex (Castrén). Only relearning changes learned content. The prediction is that medication combined with relearning outperforms either alone, and veterinary practice is built around that pairing: the drugs approved for separation-related distress in dogs are labeled for use together with behavior modification.

### Seams, sensitive periods and resilience

A system that held every part rigid could not change at all, and could not be repaired one part at a time. Systems that last keep a small set of core parts fixed and allow change at the joints between them. The fixed parts are the **panels**; the places where change is allowed are the **seams**. A good seam is a thin link that carries almost no information, a switch rather than a blueprint, so either side can be rewired without redesigning the other (Kirschner and Gerhart's "weak regulatory linkage").

**The brain's seam.** The cortex runs one shared circuit design across every region. What adapts it for a local job is a thin regional setting: the density of synaptic spines and the balance between excitation and inhibition.

**Seams close.** A sensitive period is when a seam is cut and then set:
1. Experience opens a window; maturing inhibitory neurons trigger the opening.
2. Pruning sharpens the circuit's selectivity without changing what it computes.
3. Structures called perineuronal nets close the window and lock the setting in. It cannot be dialed back without reopening the window.

**Degeneracy, not redundancy.** Redundancy means identical backups. Degeneracy means structurally different parts that can each cover the same job. A degenerate system keeps working when one part fails, and it adapts well because the spare parts are raw material for new jobs.

**Two kinds of resilience.** A system that defends one fixed standard returns quickly to a single set point but becomes brittle once conditions leave that set point's range. A system whose standard can move settles into a new stable state and persists across a range of conditions rather than at one point.

### Mental without consciousness

Learning implies nothing about experience: an isolated spinal cord can learn a reward-shaped movement (Grau). "Mental disorder" in animals can therefore mean a disorder of the learning machinery or what it has learned, without settling whether the animal feels anything. Harm carries the welfare weight, and harm also includes risk of death, injury and loss of freedom, so the definition does not depend on feeling.

### Disorders can spread

Learned patterns travel between animals through tradition. Rhesus monkeys acquire a lasting fear of snakes by watching other monkeys react to them (Mineka and Cook). A disorder of learned content can therefore have an epidemiology of transmission while still being diagnosed one animal at a time.

## 7. Using evidence from any species

The framework traces one line of descent, the one that produced all four stages. Every other lineage has its own stack, built with the same architecture, with its own developments above the point where it branched off. That includes plants, fungi, octopuses, bees, crows, parrots, whales and every domestic animal. Any animal's personality can be read as the active top of its own evolutionary stack.

**The floor of a dimension is not the floor of its best-known form.** Every dimension has older layers running beneath its named form. Agreeableness is named at Primate, where modeling another's wishes arrives, but its root, Affiliation, is present at Endotherm. When deciding the earliest stage at which an animal can have a trait or a dysfunction, use the earliest layer whose machinery the dysfunction actually requires, not the stage where the construct's most familiar form is documented.

**Five things a waypoint does not claim.**
1. **It does not claim exclusivity.** Other lineages reach the same capacities on their own. A crow that imagines or an octopus that models is the architecture working, not breaking.
2. **It does not claim priority.** Another lineage may have got there earlier, later or not at all.
3. **It does not claim absence below.** Capacities mature by degrees. A waypoint names where a capacity consolidates, not where it first appears.
4. **It does not describe any living species.** Every living species sits above its waypoint on its own branch, and its working machinery is read from its own stack.
5. **It does not claim nothing else changed.** Every function's machinery keeps being refined at every waypoint.

**The branch-point test.** Evidence from an off-thread lineage tells you about a waypoint on the thread only if the capacity predates the point where that lineage branched off. Two conditions establish this:
- the capacity appears in widely separated branches of the group, not in just one; and
- it does not depend on an organ that evolved after the group split up.

A capacity that fails either condition is that lineage's own achievement. It is neither a preview of anything nor a deficiency. Learning from consequences, for example, appears in both major branches of bilaterian animals and depends on no organ unique to either, so it dates to before they split and informs every waypoint above. By contrast, the expanded forebrain region that supports problem-solving in crows evolved after birds branched off, so it says nothing about any mammalian waypoint, however much it resembles one.

**Negative findings need more proof than positive ones.** Finding a capacity establishes it. Failing to find one does not establish that it is absent. Three explanations compete for every negative result: the lineage never had it, it had it and lost it, or the method failed to detect it. Only the first tells you anything about ancestors.

Losing a capacity is cheaper than gaining one, so methods that count gains and losses equally reconstruct ancestors as less capable than they were. A negative finding should change an assignment only if three conditions hold:
- the species tested still has the relevant architecture, rather than having lost it;
- the method detected the capacity in a positive control, a species known to have it; and
- the absence holds across widely separated branches and in a related outside group.

The rhesus macaque is a cautionary example. Two laboratories measured its visual working memory and reported roughly one item and roughly four. A method that can hide three items of working memory in a heavily studied lab primate can hide a capacity in any less-studied animal.

**Descent versus composition.** Some groups sit inside others by descent: a mammal is a vertebrate is a bilaterian. Others are built out of the level below: a complex cell contains organelles that were once free-living bacteria, and a city contains villages. Descent is settled by family trees; composition is settled by looking at what something is made of. Neither one is the reason a waypoint sits where it does.
