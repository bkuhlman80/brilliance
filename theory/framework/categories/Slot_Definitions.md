# Slot definitions — the standard wording

One definition per slot, the sentence every card author, blind reader and treatment works from. A mechanism is seated at the smallest slot whose functions its operation requires, and each definition says what requiring those functions looks like and names the nearest wrong seats. The wording is the instrument: a definition that leans pulls items the way a label does, so no doc restates a slot in its own words.

The four functions, as the definitions use them. **Effector** (E): executes; spends the unit on a change in the world. **Regulator** (R): holds a stored reference it can be wrong about and consults it; the reference is not rewritten by what the unit goes through. **Learner** (Le): a store inside the unit rewritten by what the unit's own acts go through, at the grain of what they met, so the same input met again is met differently. **Member** (Me): holds a code in common with other units and renders between its own store and that code, outward on emission and inward on uptake. A code is held in common when any user can re-emit its forms, users correct toward its forms, and it works with a receiver who shares nothing of the sender's but the code.

---

## Singles

**Effector (E).** The mechanism changes the world and does nothing else: it moves, builds, transports, transforms, secretes, emits or pulls apart, and the run ends in that change. It consults no reference, keeps no store its acts rewrite, and puts out nothing in a shared code; the same input met again is met the same way. This is the floor — an operation that requires none of the other three is here, because there is no slot with nothing in it. A gradient kept up by pumping is here. Seated here when the description of the operation is exhausted by the doing. Not here when the act is corrected toward a held value (Controller), when a later response differs because of an earlier act (Connector), when what is put out is in a code others re-emit (Starter), or when ions are pumped toward a setpoint (Regulator).

**Regulator (R).** The mechanism holds a value it can be wrong about and consults it — matches against it, reads it out, scores by it — whether the lineage set it, a higher loop set it, or the unit's own runs revised it. Correction of the unit's own state toward the value, as a pump moves ions toward a setpoint, is doing and seats with the reference at the Controller; the Regulator alone holds and consults with nothing done about it. The value can be a scalar or a map — a setpoint, a template, a target anatomy, a map of the body's state now — and a map that is tracked and restored but never revised by the unit's own outcomes is here. The reference the mechanism holds is distinct from any store another function needs in order to be that function — except for a performance code, where the kept exemplar the copier corrects toward is both the token and a value the copier can be wrong about, and the Regulator is present. Seated here when a stored value is consulted and nothing else is required. Not here when the correction is a body moved or a change made in the world (Controller), when the value moves with the unit's experience (Anticipator), when there is only a maintained state with nothing held to be wrong about (Effector), or when the value is rendered for others to hold the unit to (Operator).

**Learner (Le).** The mechanism's store is rewritten by what its own runs went through — what they met or what they produced — so the same input met again is met differently, and the change outlives what produced it. It holds no value the rewrite is scored against, does no work on the world beyond the rewrite, and shares no code. The edit passes through a run of the unit and is computed from what the run met or produced, in the store's own material; content placed in the store without a run — a variant the lineage fixed, a patch, a hand-set value — is a reference, not a rewrite, and content taken in as the thing met itself — a fragment spliced in, a file copied — is receipt, not revision. Selection inside the unit among parts of its own store by what the encounter met — junctions kept or cut, clones expanded or lost — is an edit at the grain of the encounter and is a rewrite; selection that keeps or drops the whole store on its outcome is not. The rewrite is at the grain of the encounter: what was met chooses where the edit lands, so the store afterward holds a relation among things met that the lineage did not wire. A change that only sets how much, how soon or whether a response the store already held is expressed — habituation, entrainment, damping, a gene opened or closed at a site the lineage tied to that signal — is a setting on that response, not a rewrite, however long it lasts and however it is inherited. Seated here when the whole operation is the lasting rewrite, computed from the encounter in the store's own material at the grain of the encounter. Not here when the shift disappears once the input is withdrawn (a held state, Effector or Regulator), when the runs also do something in the world (Connector), when a target is what the revising is of (Anticipator), or when the store is rewritten by what arrives in a code (Adapter).

**Member (Me).** The mechanism renders between its own store and a code held in common, outward on emission and inward on uptake, and does nothing else: it serializes out of a fixed store or parses into it, in forms any user can re-emit, that users correct toward, and that a receiver sharing nothing else can read. It cannot revise the store, hold a value beyond the code, or change the world; holding and consulting the code are what rendering is, and add no second function. Giving the rendering physical form and putting it into the world is doing, and adds the Effector. Seated here when the whole operation is the conversion — in practice the intake side, parsing and decoding into a fixed store — since putting a serialized form into the world is doing and adds the Effector. Not here when uptake rewrites the store (Adapter), when a held value is what the rendering is of (Operator), when the act that puts the rendering into the open is required (Starter), or when the form works only because the receiver shares the sender's internals — a transfer, not a rendering (Effector).

## Pairs

**Controller (E × R).** The mechanism closes a loop on a held value by acting on the world: it compares the current state to a stored value, and when there is a gap it moves, builds or fetches until the state can meet the value. The reference stays as it was, the same gap gets the same act every run, and nothing is rendered; a consolidated habit runs here whatever built it. Seated here when the correction is a world-action that holding and consulting do not exhaust, and the outcome revises nothing. Not here when the correction stays inside the unit's own state (Regulator), when the response to the same gap changes with the unit's experience (Conservator), when the target or the result crosses in a shared code (Herald), or when there is no held value to be wrong about (Effector).

**Anticipator (R × Le).** The mechanism holds a reference and a store its runs rewrite, and the two inform each other inside the unit: the store lets the reference be corrected before the error arrives rather than after, and the reference scores the rewrite. Setpoints move with predicted load; adjustment is issued ahead of demand; a modeled object's modeled state has regulatory consequence. The loop closes through the unit's own correction arm, not through action on the world, and nothing is rendered. Seated here when a held value and a lasting rewrite are both required, in either direction, and the operation is complete inside the unit: an internal operation. A behavior described as what the animal does carries the Effector, and a setting on this loop — a trait — is seated at the loop it tunes, not here. Not here when the store is simply rewritten and no value scores or steers it (Learner), when there is a reference and no rewrite (Regulator), when the correction is a movement in the world (Connector or Conservator), or when the reference or the content passes through a shared code (Counselor).

**Connector (E × Le).** The mechanism does something in the world and has its store rewritten by what that doing met or produced, with no value of its own that the write-back is scored against: the unit samples the world by acting and acts from what it sampled. Whoever picks what it meets or sets a score stands outside it. The store can contain the actor itself, and it can contain other agents. Seated here when the lasting change comes from acting and nothing held scored it; the clean case is exploration with no reward scoring it. Not here when the acts leave the response unchanged (Effector), when the rewrite involves no doing (Learner), when a held value is what the revising is of (Conservator), or when the acts or their results pass in a code others re-emit (Tester).

**Adapter (Le × Me).** The mechanism's store is rewritten by what it takes up in a shared code, so the store now holds a token the unit did not author, and what it puts out comes from the rewritten store. It holds no value beyond the code and does nothing to the world. Learning from others' renderings is here; learning from the unit's own traffic is not, and neither is reading another unit's behavior as one more event the store tracks. Seated here when the rendering and the lasting rewrite are both required, and nothing else. Not here when the store is fixed and the forms are only relayed (Member), when the revising content comes from the unit's own acts (Connector), when a held value is what the revising is of (Counselor), or when the unit also performs in the world (Tester).

**Operator (R × Me).** The mechanism holds a value distinct from the code and renders it so a second party can read it and hold the unit to it: a promise, a standard, a price, stated in forms any user can re-emit. The enforcement is outside the unit, which is what makes the value one the unit cannot quietly drop. The store and the value are fixed, and nothing is done to the world beyond rendering. The operation is holding and checking — intake and consultation; stating the value to the second party is doing and adds the Effector. Seated here when a held value is compared and passed through a code, with nothing put out and no revision. Not here when there is only the code and nothing further held (Member), when the value is met by acting or stated (Herald), when what comes back revises the value or the store (Counselor), or when the value is private (Regulator).

**Starter (E × Me).** The mechanism does something in the world in forms others can reproduce: the act is tokened, so a copier corrects toward the form rather than the result — reproduces the form where it departs from what produced the result — and it is put into the open where receivers the unit cannot see determine its fate. A form with no result for it to depart from is not shown to be tokened. Nothing returns to revise a store and no held value shapes the emission; the same form gives the same act every run. Probes, displays and broadcasts in a code are here. Seated here when an executed act is also in a code and a fixed store is all that stands behind it. Not here when a copier reproduces whatever achieves the result, or only the originator can produce the form, or the receiver merely responds, or the form has no result to come apart from (Effector), when there is only rendering and no act (Member), when the emission is governed by a reference receivers enforce (Herald), or when what comes back rewrites the store (Tester).

## Triples

Each triple is defined as much by the function it runs without as by the three it has. The check is that the mechanism runs without it, not that a description omits it.

**Conservator (E × R × Le) — runs without the Member.** The mechanism acts toward a held value and improves at meeting it from its own experience: the acts rewrite the store, the reference they are scored against stays put, and the product is consumed only by the machinery that produced it. Nothing is emitted, offered or receivable. Seated here when the response to the same gap changes with what earlier acts met, the change is steered by the held value, and nothing about the operation is read by another unit. Not here when the same gap gets the same act each time (Controller), when no held value steers the change (Connector), when there is no doing (Anticipator), or when any part of the product crosses in a code (Translator).

**Herald (E × R × Me) — runs without the Learner.** The mechanism acts toward a held value and carries that value, or its outcome, in a shared code, with nothing represented in between: it takes in a target in the code, acts until the state matches it, and puts out in the code what it did or found. The partner is not modeled; where the partner is stable, a protocol costs less than a picture. The store and the value stay as set. Seated here when an act is scored against a fixed reference and the reference, the act or the result is put out or taken up as tokened forms. Not here when nothing crosses in a code (Controller), when there is no act (Operator), when the code carries an act with no value held behind it (Starter), or when the outcome of the acts rewrites the store (Translator).

**Counselor (R × Le × Me) — runs without the Effector.** The mechanism prepares a rendering and screens it against a held value and a revisable store before any act, and the execution belongs to other machinery — or to a receiver that does not yet exist. It takes up forms of the code into its store, revises the store against what it holds, and puts out forms from the revised store; design, deliberation as the rehearsal of candidate renderings, and gating that decides a step without taking it are here. The operation is deliberation and gating — intake, rehearsal, screening, a step decided and not taken; issuing what was prepared is doing and seats the whole loop at the Translator. Seated here when the held value, the lasting rewrite and the code are all required and nothing is put out. Not here when nothing is rewritten and the unit only checks (Operator), when no further value is held (Adapter), when nothing crosses in a code (Anticipator), or when the mechanism puts out what it prepared (Translator).

**Tester (E × Le × Me) — runs without the Regulator.** The mechanism engages another unit on the other's ground: it takes up forms of a shared code, performs them in the world, and what the performance goes through rewrites its store, while it holds no value of its own that it defends or is corrected by. The references in play are the other party's. What must be taken up in another's terms cannot be held to one's own, which is why acquisition across a boundary lands here. Seated here when acting, being changed by acting, and rendering are all required and no held value governs the engagement. Not here when forms cross only because sender and receiver share internals (Connector), when the store is not rewritten (Starter), when no doing remains once revising and rendering are counted (Adapter), or when a held value governs the engagement (Translator).

## The center

**Translator (E × R × Le × Me).** The mechanism's loop closes through other units: it renders outward, uptake comes back — as a reply, a shared state, a record, a reliance — and the unit's held value and store adjust to what returned, and it acts on that. All four are required at once: a held target scores the acts, a body does them, a store is rewritten by them, and a shared code carries what crosses between units. The operation closes only when another unit's response arrives; that is what the name means, and it is what the Member alone cannot do, because the Member cannot open the receiver. Seated here when none of the four can be dropped. Not here when nothing crosses in a code (Conservator), when no doing is left once holding, revising and rendering are counted (Counselor), when the store is never rewritten (Herald), or when no held value stands beyond the store and the code (Tester).

---

*Epistemic status. The definitions were authored twice from compositions and the four function tests alone, by two seat-blind authors working in different framings — one the operation as it runs, one the difference the slot makes — and arbitrated into this set, with the forward direction of the Anticipator, the Operator's outside enforcement, the Starter's unseen receivers, the Counselor's handed-off execution and the triples' absent-function checks restored from the growing-Venn treatment where both authors had left them out. Blind readers matched each author's fifteen unlabeled definitions to the fifteen compositions at sixty of sixty; that is a ceiling, and it certifies that the wording is composition-transparent and nothing stronger. The grain clause on the Learner and the departure clause on the Starter are additions since that match and have not been re-matched. The test the set still owes is seating: mechanism descriptions with known seats, read blind against these definitions, with the blind-ratified labels as the first items.*
