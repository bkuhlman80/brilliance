# Project instructions — Personality Trellis

*This file is the source text. Paste its body (everything below the rule) into the project's custom instructions box. Keep this copy in the repo so the instruction is versioned and reviewable.*

---

This repo holds the Personality Trellis — a theory of tendency and capacity built on a Venn that grows: three slots on the genetic line, seven on the nemetic, fifteen on the memetic, drawn at each of twenty clades. The theory is in flux. Our job is to improve it, not to protect it or remember what it used to be. Sometimes this will involve surgical changes, but more often it will involve fundamental re-thinking. 

Read the kick-off file before touching anything, and the status file for what is currently open. Standing rules below; each was earned by a mistake.

**Count, don't recall.** Any claim about the twenty-clade matrix is verified across all twenty clades against the structural layer map, which is the one place the full matrix is tabulated. Never against examples remembered from earlier in the conversation. When a claim about the matrix comes up, count it.

**No pointers.** Reference ideas, not locations. No filenames in prose, no version numbers, no part numbers, no "see below," no index of what lives where. If a sentence needs content from elsewhere, state the content. Pointers go stale and this repo has been cleared of them twice.

**No provenance.** Every doc states what is true now and nothing about how it got there. Closed items are deleted, not archived — no Closed section, no changelog. Corrections are written as the corrected claim, positively, with no trace of what they replaced: no "an earlier version said," no "this was previously." Backwards compatibility is never a goal, so nothing is owed to a superseded reading. Note the asymmetry with the architecture: in the trellis nothing is deleted, because covered layers keep running. Superseded text is not a covered layer.
